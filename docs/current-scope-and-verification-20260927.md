## 이번 개발

- `tracer_transport/export_studio.py`: 기존 파일 충돌 보호와 원자적 신규 게시 흐름을 유지하면서 새 프레임의 해시를 결과 목록에 기록한다. 기존 시간축을 줄이거나 바꾸는 재게시를 거부하며, 프레임 전체를 메모리에 추가 보관하지 않는다.
- `tests/audit_saved_results.py`: 설정 해시·메타데이터 시간축·프레임 중복/경로·공간 헤더·유한값을 검사한다. 새 형식의 프레임 해시를 확인하고 구형 해시 없는 결과는 구별해 보고한다.
- `tests/test_result_integrity.py`: 유한한 수치로 파일 내용이 바뀌어도 해시 불일치를 탐지하고 구형 형식도 읽는지, 기존 시간축이 보존되는지 확인한다.
- 새 검사 산출물은 `output/normalized_tracer_verification_20260927_01/`, `output/normalized_tracer_visual_audit_20260927_01/`, `output/warehouse_geometry_verification_20260927_02/`에 별도 보관한다. 운영 결과와 합치지 않았다.

## 남은 작업과 필요한 자료

현장 해석에는 확인된 **실내** 치수와 5m 부속실의 상세 연결 형상, 실제 적재 배치·포대와 통로, 급배기·팬·문·누출 경계, 온습도 및 시간별 운전 기록이 필요하다. ClO₂ 확산·표면 반응·흡착 관련 계수는 적용 조건과 문헌 또는 실측 근거를 붙여야 하며, 별도의 위치·시간별 농도 실측과 측정 불확도가 있어야 보정·독립 검증이 가능하다.

수치 측면에서는 저장고 격자와 솔버 연결 후 격자/시간 간격을 분리한 수렴 시험, 비영 유동 사례, 경계면·질량수지 검사, 형상별 Viewer 원본 대조가 남아 있다. 구형 결과의 내용 무결성은 원래 해시가 없어 이번 구조 검사만으로 증명할 수 없다. 같은 프로젝트에 여러 프로세스가 동시에 내보내는 경우도 검증하지 않았다.
