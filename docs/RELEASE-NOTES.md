- 비대칭 적재·초기 농도 차단 · 실제 계산 영역만 결과 표시·좌표 조회

- Windows 기본 Python의 불필요한 NumPy 의존성 제거 · 원래 수치 환경 유지
- MESH-S001~MESH-S004 오류 코드·한국어/영어/일본어 안내
- 전체/절반 1초 개발 계산 비교 · 대규모 3cm 계산·수렴·실험 검증은 미완료
- 관련 검사: Python 69개·JavaScript 66개 통과 · 현재 탭의 계획·비대칭 오류·3개 언어 도움말 확인

## 실행 연결 및 결과 조회

- 새 Template에서 솔버와 호환되는 실행 양식을 명시적으로 선택
- 사일로 등가 모델의 계산 영역·다공성 영역 미리보기 제공 · 상세 덕트·격자는 별도
- 사용자 정의 사일로 입력을 논문의 최적화 후보값과 구분해 검증
- 한글·공백 설치 경로 처리, 빠르게 끝난 솔버의 완료 판정, 대기열 복구 버튼 갱신 수정
- Case별 현재 로그와 보관된 원본 로그 조회 · 초기 프레임 제외 정책 적용
- 저장된 셀 위치로 빈 표시 격자를 구분 · 평균에서 제외하고 유효한 좌표 표본 조회
- 기존 데이터·실패 기록 보존 · 계산 완료·수치 검증·문헌 재현은 별도 상태
- 한국어·영어·일본어 도움말 및 에이전트 지침 갱신
- 관련 검사: Python 66개·JavaScript 63개 통과 · 실제 탭의 언어 전환·재생·그래프·CSV 및 재시작 복원 확인
- 단순 사일로 유동 실행으로 소프트웨어 연결 확인 · 수렴·물리 검증·논문 재현 판정은 포함하지 않음

### 제한 사항

- 새 Template 정의와 솔버 설치만으로 새로운 해석 실행이 자동 연결되지 않음
- 임의 형상·물성·출력은 해당 케이스 생성기·실행기·결과 읽기 연결 필요
- 수렴 유지 구간에 따른 자동 종료 미연결
- 선상 프로파일은 최근접 저장 셀 조회 · 보간 또는 격자 세분화와 구분

- 개인 프로젝트·Raw·계산 결과·캐시·PC 설정·개인 프리셋은 Git 배포에서 제외
- 별도 진행 중인 격자 연구 변경은 이번 배포에서 제외하고 로컬에 보존
