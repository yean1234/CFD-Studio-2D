- 벡터·온도별 물성 표·대류 열전달 속성 양식 추가
- 사용자 정의 목록의 `items`·XYZ 표시·단위·범위 정의를 저장 후 복원
- Config JSON 내보내기에 입력값과 양식 포함 · 기존 값 객체 가져오기 지원
- Config 오류 코드와 한국어·영어·일본어 원인·해결 안내 제공
- 에이전트 인터페이스 v1.2의 간결한 상태 조회·문서 조회·코드별 진단 추가
- Template 출력 JSON을 기준으로 작성하고 사용자 검토 후 저장하는 안내 개정
- V1.0 후속 개선 · 기존 v1.0 태그 유지

- Config 편집·JSON 재가져오기·읽기 전용·에이전트 중단 및 입력 흐름 검사 · CFD 계산 미실행

## V1.0 후속 수정

- 2026-10-02 · `main` 반영 · 기존 `v1.0` 태그는 최초 배포 기록으로 유지
- Config 입력 순서·자료형·선택지를 Template 정의에서 구성
- 항목 이름에 따른 전역 선택지 강제 적용 제거
- 프로젝트 생성·Case·Template 편집에 같은 솔버 정의 전달
- 전체 JSON과 파일 가져오기에서 공통 판독 사용 · 값 JSON의 자료형 검사와 명시적 양식 변경 구분
- Config의 `수정` 버튼 제거 · 사용자 추가 속성 이름은 더블클릭 또는 Enter/F2로 변경
- 이름 입력 중 Enter·다른 곳 클릭으로 반영, Esc로 취소 · 이름 변경으로 계산 키·단위·값을 변경하지 않음
- 기본 항목 정의 고정 · 계산 값은 입력칸에서 편집 · 실행 스냅샷은 조회 전용
- 검사: Python 30개, JavaScript 전체 144개, 브라우저 120개 통과
- 기존 프로젝트·프리셋·계산 결과 보존 · 새 CFD 계산 미실행
- 기존 솔버별 파일 호환 규칙과 실행 지원 범위는 유지

### 기능

- 프로젝트별 독립 Case·Config 스냅샷·대기열·결과 관리
- CFD Template의 솔버·입력 양식·초기 형상 정의와 Template별 프리셋
- Config·3D 형상·JSON의 독립 패널, 요소별 물성·변환·사용자 속성 편집
- JSON 버튼을 전체 문서·선택 요소·주요 분류로 정리
- 중복 적재배치 입력 제거, 기존 요소 목록에 추가·편집하는 공통 동작 적용
- 3D Virtual과 Data Sheet의 일관된 Case 선택·결과 준비율·내보내기
- 연속 재생바·공통 물리량 표시 정의
- Data Sheet 왼쪽 평균/좌표 시계열과 오른쪽 선상 프로파일
- 에이전트 JSON 입력·사용자 검토·조작 상태·일시정지 안내

### 제한 사항

- 새 Template 정의와 솔버 설치만으로 새로운 해석 실행이 자동 연결되지 않음
- 임의 형상·물성·출력은 해당 케이스 생성기·실행기·결과 읽기 연결 필요
- 수렴 유지 구간에 따른 자동 종료 미연결
- 선상 프로파일은 최근접 저장 셀 조회 · 보간 또는 격자 세분화와 구분
- 저장고 예제의 격자·시간간격 수렴 기준 미달, 독립 실험 검증·7일 전체 연결 계산 미완료
- 개인 프로젝트·Raw·계산 결과·캐시·PC 설정·개인 프리셋은 Git 배포에서 제외
- 별도 진행 중인 격자 연구 변경은 이번 배포에서 제외하고 로컬에 보존
