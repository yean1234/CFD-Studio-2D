# CFD Template

- CFD Studio V1.0

## 구성

| 항목 | 보관 내용 |
|---|---|
| CFD Template | 솔버·해석 조건·Config 양식·자료형·단위·초기 형상 |
| 프리셋 | 해당 Template에서 재사용할 입력값 |
| 프로젝트 Config | 생성 시 입력하거나 프리셋에서 가져온 값의 사본 |
| Case Config | 실행별 독립 입력값과 시작 시점 스냅샷 |

## 생성

- **CFD Template 리스트 → +**
- 설문 작성 → **솔버 추천** → 기능·출력·제한 비교 → 솔버 선택
- **여기에 없음**: 등록된 양식으로 지원할 수 없는 조건 표시 · 선택 수정 가능
- **양식 생성** → 이름·설명 → **양식 편집**
- 필수 항목·자료형·단위 확인 · 초기 형상과 요소 정의 → **저장 → Template 저장**
- 물성·초기 조건 등 실행 입력값은 프로젝트에서 작성 · 양식 메타데이터와 초기 형상은 Template에 보존
- 형상 이름으로 물질 상태나 물성을 추정하지 않음 · 고체·액체·기체와 필요한 속성은 명시적으로 입력
- **JSON 가져오기 / JSON 내보내기**: Template 정의 파일 편집
- **설문 수정** 후 재생성 전까지 기존 양식 유지
- 추천은 등록된 지원 조건 기준 · 솔버 설치 여부·속도 순위와 별개
- 기존 Template의 솔버는 고정 · 다른 솔버는 새 Template 생성

## Config

- **새 프로젝트**에서 Template 선택 → 프리셋 선택 또는 직접 입력 → **Config 입력**
- 왼쪽: 형상 요소·물리 속성·공통 Config 목록
- 가운데: 3D 형상 · 네임태그로 요소 선택
- 오른쪽: 주요 분류의 **JSON** 선택 시 원문 편집
- 요소의 위치·크기·적재 배치는 **형상 및 계산 영역**에서 정의 · 별도 프로젝트 전용 중복 입력 제거
- **+ 요소**는 현재 선택한 요소 목록에 추가 · 목록이 없으면 일반 요소로 시작
- **영역 공통 속성**은 해당 요소 목록에 공통으로 적용되는 값
- 종료 조건·격자·계산 출력·측정 위치 등은 공통 Config에서 편집
- JSON은 전체 Config·전체 공간 정의·선택 요소·기하 형상·변환·물리 속성·사용자 속성 묶음·공통 주요 분류에 제공
- 개별 숫자·배열 항목·좌표 성분에는 JSON 버튼을 반복 배치하지 않음
- **JSON 저장**은 초안 반영 · Config와 상위 생성창의 **저장**으로 최종 확정
- 실행한 Case는 조회 전용 · **이 Config로 새 Case**로 복사하여 변경

## 프리셋

- **프리셋에 저장** 기본 해제
- 체크 시 새 이름으로 별도 저장 · 기존 프리셋 자동 덮어쓰기 없음
- Template별 프리셋 분리 · 다른 Template의 값 자동 적용 차단
- 프로젝트 기본 프리셋 변경은 이후 새 Case에만 적용

## 실행과 호환성

- 연결된 Template: 지원되는 형상·입력 범위에서 실행·결과 조회
- 신규 범용 Template: 양식·Config·프로젝트·프리셋 보관 지원
- 임의 Config 실행에는 케이스 생성·솔버 실행·결과 변환 어댑터 필요
- 솔버 실행 파일 설치 확인과 Studio 실행 연결은 별개
- 입력 검사는 자료형·필수값·범위 확인 · 물리 검증과 구분
- 기존 Template ID·프리셋 ID·프로젝트·Case·결과 경로 유지
- 내부 `form_id`와 등록 파일명은 데이터 호환을 위해 유지
- 기존 전용 솔버의 필드 대응 규칙 유지 · 임의 형상을 모든 솔버가 계산하는 것은 아님
