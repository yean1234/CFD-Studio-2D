# CFD Template

## 구성

| 항목 | 보관 내용 |
|---|---|
| CFD Template | 솔버·해석 조건·Config 항목·자료형·단위 |
| 프리셋 | 해당 Template에서 재사용할 입력값 |
| 프로젝트 Config | 생성 시 입력하거나 프리셋에서 가져온 값의 사본 |
| Case Config | 각 실행의 독립 입력값과 실행 시점 스냅샷 |

## Template 생성

- **CFD Template 리스트 → +**
- 해석 대상 → 유동·시간 → 영역·종료 순서로 설문 작성
- **여기에 없음**: 해당 조건을 지원하는 등록 솔버·양식이 없음을 표시 · 지원하지 않는 항목 안내 후 추천·생성 중지 · 선택 수정 또는 취소 가능
- **솔버 추천** → 조건에 맞는 후보의 기능·출력·제한 비교 → 솔버 선택
- **양식 생성** 후 이름·설명 입력
- **양식 편집**에서 Key·Type·Unit 확인 → **Apply → Template 저장**
- **설문 수정**으로 조건 변경 · 양식 재생성 전까지 기존 양식 유지
- 물성·치수·초기값·시간간격은 미입력 상태
- 솔버명·단위·알고리즘·선택한 해석 조건은 양식 정의에 포함
- **Download JSON / Import JSON**은 Template 정의 파일에 적용
- 설치 여부·성능 순위가 아닌 등록된 양식 지원 조건에 따른 후보 제시
- 기존 Template은 솔버 고정 · 다른 솔버는 새 Template 생성

## 프로젝트 생성

- **새 프로젝트**에서 이름·폴더·설명·CFD Template 지정
- **기본 프리셋 → 직접 입력 → Config 입력**으로 빈 양식 작성
- 기존 값 사용 시 해당 Template의 프리셋 선택
- **Config 입력**에서 값 작성·JSON 가져오기 → **Apply → 저장**
- 빈 사전형 항목은 JSON 객체로 작성 가능
- **프리셋에 저장**은 기본 해제
- 체크 시 새 이름으로 별도 저장 · 다른 Template의 프리셋 사용 차단
- 기존 입력값 프리셋과 앞선 Case는 변경하지 않음

## 실행 범위

- 기존 연결 Template은 기존 실행·결과 조회 지원
- 신규 범용 Template은 양식·입력값·프로젝트·프리셋 저장 지원
- 임의 Config의 OpenFOAM 파일 생성·실행·결과 변환은 실행기 연결 필요
- 솔버 설치 확인과 실행기 연결은 별개
- 필수 항목 검사는 자료형·누락·명시된 범위 검사
- 물리적 타당성·격자 품질·수렴·실험 검증은 별도

## 호환성

- 기존 Template ID·프리셋 ID·프로젝트·Case·결과 경로 유지
- 기존 설정값은 **기존 입력값** 프리셋으로 접근
- 등록 파일명과 내부 `form_id` 키는 기존 데이터 호환을 위해 유지
- 프로젝트 생성 시 Config는 프로젝트 파일에 사본으로 저장
- Template별 프리셋은 Studio 등록부에 저장
