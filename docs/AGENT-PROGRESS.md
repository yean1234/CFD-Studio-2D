# 에이전트 작업 진행

- 사용법: [한국어](CFD-STUDIO-AGENT-GUIDE.md#작업-진행-표시) · [English](CFD-STUDIO-AGENT-GUIDE.en.md#visible-progress) · [日本語](CFD-STUDIO-AGENT-GUIDE.ja.md#作業進行表示)
- 자료 확인·초안 작성·코드 수정·검사·화면 조작을 구분하는 상태 전송 기능
- 자동 화면 조작 연결이나 CFD 실행 경로가 아님 · 화면 조작 연결 실패 중에도 개발 진행 상태만 전달 가능
- 서버에 상태가 도착했는지와 보이는 탭에 표시됐는지를 별도로 확인
- 실행 중인 Studio가 구버전이면 먼저 입력·계산을 보존한 뒤 재실행 필요

## 통신 계약

| 항목 | 정의 |
| --- | --- |
| 경로 | `GET /api/agent/activity`, `POST /api/agent/activity` |
| 범위 | 루프백 주소 · JSON · `X-CFD-Activity: 1` · 다른 출처 요청 차단 |
| 에이전트 동작 | `start`, `update`, `finish` · 상태만 전송 |
| 화면 동작 | `seen`, `pause`, `resume` · 같은 출처의 브라우저 요청 |
| 담당 | start에서 발급한 토큰으로 update·finish 수행 · GET에는 토큰 미포함 |
| 수명 | 마지막 갱신 후 120초 · 새 담당이 확보하면 이전 토큰 무효 |
| 일시정지 | 갱신·새 담당 확보 차단 · 연결 만료 후에도 유지 · finish는 해제하지 않음 |
| 화면 수신 | 보이는 탭이 같은 revision을 렌더링한 뒤 seen · 8초간 유효 |
| 표시 주기 | 2초 · 요청 시간 제한 3초 · 이전 revision 응답 무시 |
| 기록 | 서버 메모리에 최근 20건 · Config·사용자 파일·계산 상태 수정 없음 |

- CLI 기본 응답은 최근 이력을 생략 · 필요할 때만 `--history` 추가
- CLI의 `--wait-visible`: 최대 5초 동안 해당 상태의 화면 수신 확인
- 상태 수신은 특정 사용자 탭 조작권·사용자 검토·저장·계산 승인과 별개
- 탭은 숨겨져 있으면 화면 수신을 보내지 않음 · 다른 탭의 수신 여부는 특정 사용자 화면 접근을 증명하지 않음
- 중단은 협조적 제어 · 외부 에이전트는 각 작업 전에 응답을 확인하고 일시정지 시 다음 명령을 보내지 않아야 함
- 이미 진행 중인 셸 명령·CFD는 중단하지 않음 · LLM 제공자 프로세스를 강제 정지하지 않음
- 상태 API는 로컬 개발 도구용 · 다중 사용자 인증이나 외부 공개 서버로 사용하지 않음
- 일시정지 우회를 위한 탭·서버 재시작 금지

## 오류 코드

| 코드 | 원인 | 다음 행동 |
| --- | --- | --- |
| `PAUSED` | 사용자 일시정지 | 상태만 확인하고 사용자 재개 대기 |
| `ACTIVITY_BUSY` | 유효한 담당 존재 또는 표시 탭 수 한계 | 담당 종료·만료 확인 · 강제 교체 금지 |
| `ACTIVITY_OWNER_MISMATCH` | 다른 담당 토큰 또는 서버 재시작 | 세션·서버를 재확인 · 이전 작업을 자동 재전송하지 않음 |
| `ACTIVITY_FINISHED` | 종료한 세션 갱신 | 새 작업이면 새 세션 파일로 시작 |
| `ACTIVITY_STALE` | 이미 바뀐 revision의 화면 수신 | 현재 상태 재조회 후 표시 |
| `ACTIVITY_INVALID_INPUT` | 잘못된 JSON·자료형·크기·단계 | 이름 80자·설명 240자·요청 4096바이트·허용 단계 확인 |
| `ACTIVITY_UNKNOWN_ACTION` | 지원하지 않는 동작 | 상태 전용 동작만 사용 · CFD는 공개 화면 명령 사용 |
| `ACTIVITY_FORBIDDEN` | 루프백·출처·JSON 헤더 조건 불일치 | 같은 Studio 출처와 공식 클라이언트 사용 |
| `ACTIVITY_UNAVAILABLE` | 서버·상태 기능·세션 파일 접근 실패 | 서버 버전·포트·파일 확인 · 기존 계산을 임의 재시작하지 않음 |

| CLI 종료 코드 | 의미 |
| --- | --- |
| `0` | 요청 성공 · 화면 수신 요구 시 displayed 확인 |
| `2` | 오류 · 상세 error 확인 |
| `3` | 일시정지 · 다음 작업 중단 |
| `4` | 화면 수신 미확인 · 표시 완료로 보고하지 않음 |

## 검사

- `tests/test_agent_activity.py`: 담당 충돌·일시정지·만료·화면 수신·입력 검사·출처 검사·CLI 세션 보존
- `tests/test_agent_activity.js`: 표시 구분·숨겨진 탭·응답 순서·연결 끊김·서버 재시작
- `tests/serve_agent_activity_fixture.py`: 프로젝트나 CFD에 접근하지 않는 독립 화면 검사 서버
- `tests/browser_agent_header.js`: 실제 Studio에서 진행 표시가 CFD·Viewer·환경 설정·도움말 버튼을 가리지 않는지 확인 · 입력·프로젝트·대기열 변경 없음
- 화면 검사: 상태 수신, 일시정지 후 CLI·화면 명령 차단, 재개, 모달 위 표시, 다국어 문구
- 이 검사는 CFD 계산·수치 검증·실험 검증이 아님
