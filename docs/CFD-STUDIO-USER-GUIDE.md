# 사용법

- 진행 순서: 프로젝트 선택 → 실행 설정 → 계산 → 실행 선택 → 결과 보기
- 모델·단위·검증 상태: [설명서](CFD-STUDIO-MANUAL.md)

## 실행

- `cfd_studio/실행.bat` 실행
- 왼쪽 프로젝트 선택
- **새 CFD 실행** 선택
- 기본값 또는 저장된 설정 선택 → **불러오기**
- 왼쪽 항목을 눌러 계산 시간·격자·형상·물성·초기조건 수정
- **설정 검색**: 이름 또는 설정 키로 항목 검색
- **전체 JSON**: 전체 입력 확인·편집
- **계산 시작** 선택
- 실행 목록에서 진행 상태·솔버 로그 확인
- 한 번에 한 실행 진행

![프로젝트](assets/warehouse-guide/projects.png)

## 설정

- **설정 저장**: 입력한 실행 이름으로 설정 보관
- **JSON 내보내기**: 설정 파일 다운로드
- **JSON 가져오기**: 설정 파일 불러오기
- 같은 이름의 저장 설정: 덮어쓰기 차단, 다른 이름으로 저장
- 프로젝트: 이름과 실행 목록 보관
- 계산 입력: 실행마다 독립적으로 보관
- 다음 실행: 기본값·저장 설정·이전 실행 설정 중 선택

![실행 설정](assets/warehouse-guide/run-settings.png)

- 이중액침 설정: 수조·층 구성·보드·발열·코일·물성·상변화·격자·계산·출력 편집
- 저장고 설정: 시간·형상·적재·유동·열전달·초기 농도·외기온·격자 편집
- 입력 편집 가능 여부와 물리적 타당성: 별도 판단

## 설정 조회

- 실행 목록에서 실행 선택 → **설정 보기**
- Viewer에서도 왼쪽 또는 오른쪽 **설정 보기** 사용
- 실행 전 원본 입력: 조회·내보내기 가능
- 기존 실행 입력: 수정하지 않음
- **이 설정으로 새 실행**: 입력을 가져와 새 계산 준비
- 창 닫기: 보고 있던 결과로 복귀

![설정 조회](assets/warehouse-guide/settings-readonly.png)

## 결과 보기

- 실행 선택 → **결과 보기** 또는 상단 **Viewer**
- 왼쪽 **실행 선택**: 같은 Viewer에서 실행 전환
- 왼쪽 프로젝트 선택: 해당 프로젝트의 이전 선택 실행으로 전환
- **실행 목록** 또는 **CFD**: 로그와 실행 목록으로 복귀
- 저장고 결과: 실행별 재생 위치·물리량·시점 유지
- 유지 범위: 현재 브라우저 탭, 새로고침 전까지

![실행 결과](assets/warehouse-guide/execution-results.png)

## 재생

- 아래 시간 막대: 저장 프레임 선택
- **◀ / ▶**: 이전·다음 프레임
- **재생 / 일시정지**: 연속 재생 제어
- 재생 속도: 초당 표시 프레임 수
- 실제 계산 시간: 시간 막대 옆 숫자 확인
- 드래그: 회전
- Shift+드래그: 이동
- 휠: 확대·축소
- **시점 초기화**: 기본 시점 복원

## 물리량

| 선택 | 표시 내용 |
|---|---|
| 농도 | ClO₂ 농도, mg/m³ |
| 온도 | 셀 온도, °C |
| 유속·방향 | 속력과 흐름 방향, m/s |

- **표시 영역 → 중앙 통로 단면**: 내부 흐름 확인
- 정규화 시험 농도: C/C_ref, 실제 농도와 구분
- 점: 셀 표본
- 화살표: 흐름 방향과 상대 크기
- 색 범위: 프레임마다 변경, 범례 숫자 확인

![유속](assets/warehouse-guide/velocity.png)

## 위치 조회

- 오른쪽 **위치·시간 조회** 펼치기
- X·Y·Z·시간·최대 거리 입력 → **조회**
- 예제: X=39 m, Y=12.5 m, Z=3 m, 시간=270 s, 최대 거리=3 m
- 조회값 아래: 셀 번호·셀 중심까지 거리·원본 파일 확인
- 저장 시점 사이: 선형 보간
- 최대 거리: 가장 가까운 셀 중심까지 허용 거리

![위치 조회](assets/warehouse-guide/query.png)

## 저장

- **화면 저장**: 현재 3D 화면 PNG, 조작 패널 제외
- **CSV 저장**: 현재 프레임의 표시용 표본 데이터
- CSV 항목: 시간·셀 번호·좌표·농도·온도·유속 성분
- CSV 범위: 현재 프레임 표본 전체, 단면 선택과 무관
- **영상 저장**: 첫 프레임부터 재생하며 WebM 기록
- **영상 저장 종료**: 기록 종료·다운로드
- 영상 기록 중 실행 전환: 다른 실행의 결과가 섞이지 않도록 기록 취소
- **원본 파일**: 계산 원본 경로 확인
- **모델·검증**: 모델과 가정·검증 상태 확인

## 이중액침

- 왼쪽 **이중액침** 프로젝트 선택
- **3mm_Test** 선택 → **결과 보기**
- 기존 Viewer의 기포·유속·온도·상분율·재생·데이터 관리 기능 사용
- **설정 보기**: 해당 실행의 원본 입력 확인
- 보존 구간: 0~52.49초, 5,250프레임
- 원본 위치: `D:\CFD Studio\Project\3mm_Test`
- 원본 복사·이동 없이 연결

![이중액침](assets/warehouse-guide/immersion.png)

## 문제 해결

| 상황 | 확인 항목 |
|---|---|
| 결과 미표시 | 원본 존재 여부, 실행·출력 검사 결과 |
| 종료시간 이후 미표시 | 해당 실행의 계산 범위 |
| 조회 오류 | 좌표·시간·허용 거리 |
| 원본 불일치 | 원본·배열 보존 후 검사 기록 확인 |
| 이전 화면 표시 | 브라우저 새로고침 |
