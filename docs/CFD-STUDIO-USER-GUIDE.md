# 사용법

- 진행 순서: 실행 → 결과 선택 → 농도·온도·유속 표시 → 위치 조회
- 모델·단위·검증 상태: [설명서](CFD-STUDIO-MANUAL.md)

## 1. 실행

1. `cfd_studio/실행.bat` 실행
2. 오른쪽 위 **`!` → 사용법 → 저장고 수송 결과** 선택
3. **완료된 결과**에서 `warehouse_transport_porous_r4_20260928_01` 선택

- 최초 설치: [설치 안내](../cfd_studio/README.md) 참고
- 이미 실행 중인 경우: 기존 브라우저에서 접속
- 예제 규모: **119,040셀 · 0–300초 · 6프레임**
- GitHub 배포 범위: 전체 계산 원본 제외
- 새 PC에서 예제 미표시 시: [계산 실행](warehouse-porous-grid-review-20260928.md#재현) 참고
- 새 저장고 CFD 실행: 명령줄 사용, Study 실행 버튼 미연결

![도움말](assets/warehouse-guide/help.png)

- 그림 1: 우측 상단 `!`의 사용법 탭
- 사용법: 화면 조작
- 설명서: 모델·단위·검증 상태
- 촬영 환경: 실행이 차단된 검토 화면

## 2. 결과 선택

- **저장 프레임** 막대로 시간 선택
- 오른쪽 끝: **300초**
- 확인 항목: **다공성 곡물**, **누출 제외**, **격자 수렴 기준 미달**

![결과 선택](assets/warehouse-guide/selection.png)

- 그림 2: 계산 선택과 검증 상태
- 계산 완료: 지정 시간까지 실행·출력 완료
- 정확도 검증: 별도 판정

## 3. 물리량 표시

- **표시할 물리량**에서 항목 선택

| 선택 | 표시 내용 |
|---|---|
| 농도 | ClO₂ 농도, mg/m³ |
| 온도 | 계산된 실내 온도, °C |
| 유속·방향 | 속력과 화살표 방향, m/s |

- 내부 흐름 확인: **표시 영역 → 중앙 통로 단면**
- 회전: 마우스 드래그
- 확대·축소: 마우스 휠

![유속](assets/warehouse-guide/velocity.png)

- 그림 3: 300초 중앙 통로 단면의 유속·방향
- 점: 셀 표본
- 화살표: 흐름 방향
- 범례: 시간·단위·값 범위
- 색 범위: 프레임마다 변경

## 4. 위치 조회

1. **위치·시간 조회**에 아래 값 입력
2. **조회** 선택

| x | y | z | 시간 | 최대 거리 |
|---:|---:|---:|---:|---:|
| 39 m | 12.5 m | 3 m | 270 s | 3 m |

![위치 조회](assets/warehouse-guide/query.png)

- 그림 4: 농도·온도·유속 조회 결과
- 조회값 아래: 선택한 셀까지의 거리, 원본 C/T/U 파일
- 270초 값: 저장된 240초·300초 사이 선형 보간
- 최대 거리: 조회 좌표와 가장 가까운 셀 중심 사이의 허용 거리
- 좌표 기준: 저장고 한쪽 끝 x=0, 폭 방향 y, 바닥 z=0

## 문제 해결

| 상황 | 확인 항목 |
|---|---|
| 결과 미표시 | 계산 원본 존재 여부, 실행·출력 검사 통과 여부 |
| 300초 이후 미표시 | 해당 사례의 종료시간 300초 |
| 조회 오류 | 좌표·시간 범위, 셀까지의 거리 |
| 원본 불일치 | 원본·배열 보존, 해당 계산의 검사 기록 확인 |
| 이전 도움말 표시 | 계산 종료 후 Studio 재실행 |
