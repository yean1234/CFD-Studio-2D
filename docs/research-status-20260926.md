자동 검사: 42개 중 40개 통과, 2개는 matplotlib 미설치로 건너뜀. 테스트는 입력 불변성, 시드 재현, 중복 예약, 실패 후 재시도, 환경 오류 보류, 코드 변조, 패키지 경로/해시, 기하 제약과 미지원 저장고 실행 차단 등을 포함한다.
