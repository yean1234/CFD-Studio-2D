# 결과 시각화

## 공통 표시 정의

- 정의 파일: `cfd_studio/internal/viewer_presentation.js`
- 프로젝트 이름과 관계없이 물리량의 의미·자료형·단위에 따라 표시
- 기존 결과 형식을 읽는 모듈은 데이터 해석 담당 · 공통 정의는 항목 이름·표시 방식·재생 시간 담당
- 기존 결과의 좌표·값·단위는 보존 · 화면 표시만 변경

| 결과 데이터 | 자료형 | 3D 표시 | Data Sheet |
| --- | --- | --- | --- |
| 온도 | 셀 스칼라 | 색상 분포·범례 | 저장 시점별 평균·좌표 조회 |
| 농도·흡착량 | 셀 스칼라 | 색상 분포·범례 | 해당 결과에 정의된 통계·좌표 조회 |
| 압력 | 셀 스칼라 | 색상 분포·범례 | 저장 시점별 통계·좌표 조회 |
| 난류 운동에너지 | 셀 스칼라 | 색상 분포·범례 | k·epsilon 등 제공 항목별 그래프 |
| 유속 | 셀 벡터 | 방향 화살표·흐름 마커·크기 범례 | 속력 및 X·Y·Z 성분 |
| 상분율 | 셀별 성분 비율 | 상별 체적 분포 | 성분별 저장값 |
| 기포 | 위치·크기 및 부피 | 입자·기포 형상 | 저장된 부피 시계열 |
| 관측·이력 | 시계열 | 공간 좌표가 있는 경우 해당 표시 기능 사용 | 시계열 그래프 |
| 공간 형상 | 경계·격자·영역 | 외곽선·면·영역 | 수치 결과와 별도 |

- 실제 파일에 있는 결과만 표시 · 저장되지 않은 물리량을 생성하지 않음
- 온도·농도·압력은 서로 다른 물리량으로 취급 · 임의로 같은 색상 단위에 합치지 않음
- 압력의 `m²/s²`와 `Pa`는 구분 · 기존 결과 읽기 모듈이 변환 근거를 가진 경우에만 변환
- `kg/m³` 농도를 `mg/m³`로 변환하는 기존 저장고 데이터 처리 유지
- 사용자 정의 이름과 실제 결과 목록은 해당 결과의 메타데이터 사용

## 재생

- 재생바는 첫 저장 시점부터 마지막 저장 시점까지의 재생 시간 비율로 표시
- 저장 프레임 사이에서도 연속 이동 · 불규칙한 저장 간격도 실제 시간 간격에 비례
- 막대를 드래그하면 해당 시간으로 이동 · 재개 시 이전 저장 프레임으로 되돌아가지 않음
- 좌우 방향키는 저장 프레임 단위 이동 유지
- 단일 프레임은 시간 탐색 비활성
- 물리시간이 없는 정상 해석은 기존 반복 횟수 기반 재생 축 사용 · 물리시간으로 해석하지 않음
- 저장고·정규화 추적자는 기존 시간 보간 유지 · 저장고 보간은 같은 셀 좌표와 표본 순서가 확인된 프레임에 적용
- 기존 다른 결과는 각 읽기 모듈의 저장 프레임 표시 방식 유지 · 재생바의 연속 이동이 모든 물리량의 보간을 의미하지 않음
- 버퍼가 준비되지 않으면 결과 읽기를 기다림 · 시각화 재생이 CFD 실행 상태를 변경하지 않음

## 지원 범위

- 이중액침·단상 저장고·정규화 추적자·저장고 연결 계산의 기존 결과 형식에 공통 정의 적용
- 그래프는 기존 결과 목록에서 제공하는 물리량·단위·통계 사용
- 파일 읽기와 격자·형상 생성에는 기존 형식별 모듈 유지
- 새로운 파일 형식·텐서장·미지원 물리량에는 읽기 및 표시 연결 추가 필요
- 공통 정의에 이름만 추가해도 새로운 솔버의 결과를 자동으로 해석하는 구조는 아님
- 시각화·수치 검사·물리 및 실험 검증 상태는 별도

## Data Sheet

- 왼쪽 시간 그래프: 전체 평균 / 특정 좌표 선택, 최대 3개 물리량, 선·막대·산점도
- 오른쪽 선상 프로파일: 저장 시점·물리량·시작점·끝점·표본 수 지정
- 프로파일은 2~256개의 균등 간격 지점에서 최근접 저장 셀 조회
- 시간 보간·공간 보간 없이 저장된 값 사용, 표본 수 증가는 CFD 격자 세분화와 별도
- 정규 격자 파일: 빈 셀·상분율 마스크·기존 빈 평면 처리 유지, 한 프레임을 한 번 검증·해독
- 저장고 배열: 해당 저장 시점의 원본장 대조 후 실제 셀 중심에서 추출
- 결과 파일과 계산 입력은 읽기 전용
- 프로파일 CSV: 거리·값·저장 시점·입력 좌표·실제 셀 중심·셀까지 거리·추출 방식
- 프로파일 PNG: 물리량·단위·저장 시점·양 끝점·그래프·선택한 X·Y 포함
- 경계 전용 값·미저장 변수·PSD·POD·DMD는 생성하지 않음
