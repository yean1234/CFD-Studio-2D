# 기능·UX 검토 및 수정

검토일: 2026-09-26 작업분. 기존 프로젝트·Raw·협력 자료는 수정하거나 삭제하지 않았다. 전용 브라우저 세션과 별도 소규모 시험 데이터를 사용했다. 이 문서는 모든 환경에서 무결함을 보증하는 문서가 아니라 확인한 결함, 수정, 재현 시험의 범위를 기록한다.

## 먼저 확인할 제한

**실제 저장고 형상 후보를 ClO₂ CFD로 실행하는 연결은 아직 구현되지 않았다.** 형상 후보 생성·제약 검사·3D 미리보기·불변 입력 저장은 가능하다. 실제 실행은 정규화 추적자 검증 예제에 한정한다. 저장고 후보 실행 요청은 명시적으로 거부하며 검증 예제를 대신 실행하지 않는다.

## 확인하고 수정한 문제

| 중요도 | 문제 | 수정 및 확인 |
|---|---|---|
| 높음 | 실험 변경·새로고침 후 저장된 변수 대신 기본값이나 다른 실험 초안이 표시됨 | 실험별 초안, 확정값 복원, 저장 성공 후 초안 정리, 명시적 되돌리기 |
| 높음 | 실험 선택 해제·느린 응답 도착 후 이전 실험 실행 버튼이 유효해질 수 있음 | 선택·편집 세대 검사, 미선택 결과 비우기, 작업 중 입력 잠금 |
| 높음 | 다른 창의 새 버전이 수정 중 입력과 섞이거나 이전 버전으로 실행됨 | 버전 충돌 검사와 명시적 최신값 불러오기, 수정 중 실행 차단 |
| 높음 | 추적자 Viewer가 액침·저장고 CFD 출력 체크박스와 설정에 영향을 줌 | 실행 설정과 Viewer 설정 분리, 모드 전환 회귀 시험 |
| 높음 | 8배속 끝 구간에서 추적자 캐시를 잘못 확인해 버퍼 대기가 끝나지 않음 | 해당 필드의 현재 프레임을 준비·검사, 끝 지점 도달 및 다시 재생 확인 |
| 높음 | 중단된 실행이 전체 대기열을 막지만 해제 절차가 없음 | 중단 확인·사유 기록, 소유권 잠금 확인, 실패 기록 보존, 수동 대기열 재개 |
| 높음 | 내보내기 도중 버전 변경 시 입력과 결과가 섞일 수 있음 | 같은 DB 조회 스냅샷으로 입력·비교·패키지 구성 |
| 보통 | 설계 JSON 오류로 초안이 사라지거나 잘못된 가져오기가 폼을 부분 변경 | 원문 초안 보관, 전체 검사 후 반영, 이전 미리보기 무효화 |
| 보통 | 일시정지 시 농도장이 직전 저장 프레임으로 되돌아감 | 정지 시에도 표시된 물리시간에서 보간, 재생 중 갱신 빈도 제한 유지 |
| 보통 | 로딩 중 누른 재생 요청이 사라짐 | 첫 프레임 준비 후 재생 요청 반영 |
| 보통 | 후보 실패와 설치·환경 실패를 동일하게 처리 | 환경 실패만 대기열 보류, 후보 실패는 기록 후 다음 후보 진행 |
| 보통 | 중첩 입력·패키지 구조 오류가 서버 오류로 이어짐 | 자료형·수치 정의역·manifest 검사, 사용자 입력 오류 응답 |
| 보통 | 저장고 프리셋 변경·저장 중 폴링으로 편집값을 잃을 수 있음 | 미저장 변경 확인, 저장 중 입력 잠금, 실패 시 초안 유지 |
| 보통 | 연구 화면 진입 링크와 작은 화면 가독성이 부족 | Studio 상단 링크, 반응형 배치·차트, 후보 키보드 선택 |

OpenFOAM 자동 탐색은 `/usr/lib/openfoam` 및 `/opt` 설치 경로를 확인한다. 물성·치수·공급량의 연구값은 이번 UX 수정에서 변경하지 않았다. 입력의 양수·비음수 등 명백한 정의역만 검사하며 문헌 기반 범위를 임의로 만들지 않는다.

브라우저 합계는 49개 확인 항목이며 49개의 독립 물리 검증 시험이라는 의미가 아니다. 복구 화면의 가짜 실행기는 실제 CFD 검증에서 제외한다. 기존 사용자 Chrome 창에는 접근하지 않았다.

2026-09-27 공개 전 재검사에서 Python 62개, JavaScript 15개, Windows 추가 검사 20개가 다시 모두 통과했다. 이번 재검사에서는 브라우저·실제 솔버 인수 시험을 반복하지 않았다. [빠른 사용 안내](quickstart-ko.md)를 추가하고, Raw·개인 환경·실험 산출물의 Git 제외와 공개 대상의 인증정보 패턴을 확인했다.

최종 소규모 인수 시험은 OpenFOAM v2312 `porousTracerFoam`, 1,280셀, 모사 0~1 s, 계산 간격 0.005 s, 저장 간격 0.1 s의 3개 후보를 순차 실행했다. 모두 0초를 포함한 11프레임을 저장했고 수치 검사를 통과했다. 질량 상대 오차는 최대 약 4.51e-15였다. 후보별 솔버 구간 실제 소요시간은 약 0.22~0.24초, 전체 후보 처리 약 1.30~1.33초였다. 이 시간은 소규모 검증 예제의 측정값이며 실제 저장고 처리시간 견적이 아니다.

패키지 내보내기·가져오기 후 같은 OpenFOAM 빌드에서 대표 사례를 재계산했다. 농도장 최대 절대 차이는 0이었다. 이 결과를 실제 ClO₂ 반응·누설·쌀 흡착 모델의 검증으로 해석하지 않는다. UI를 통한 별도의 3후보 순차 실행과 패키지 다운로드도 통과했다.

## 재실행 방법

저장소 루트의 별도 시험 환경에서 실행한다. NumPy 및 matplotlib가 필요하다. 운영 프로젝트 폴더를 시험 출력 경로로 지정하지 않는다.

```bash
python -m unittest discover -s tests -v
node --test tests/test_viewer_review.js
source /usr/lib/openfoam/openfoam2312/etc/bashrc
python -m study_platform.smoke output/study_new_acceptance
```

전용 Playwright CLI 세션에서 Studio 검토 서버를 연 뒤 다음 함수를 실행한다. `browser_study_workflow.js`는 이름에 UX 검토가 붙은 새 실험과 실제 소규모 계산을 만든다. Viewer 검사는 그 결과의 `3D 보기`로 이동한 뒤 실행한다. 테스트 함수 파일은 CLI가 괄호로 감싸 실행하므로 마지막 함수 표현식 뒤에 세미콜론을 추가하지 않는다.

```bash
npx --yes --package @playwright/cli playwright-cli -s=cfd-review run-code --filename tests/browser_study_workflow.js
npx --yes --package @playwright/cli playwright-cli -s=cfd-review run-code --filename tests/browser_design_workflow.js
npx --yes --package @playwright/cli playwright-cli -s=cfd-review run-code --filename tests/browser_viewer_workflow.js
```

복구 검사는 운영 자료와 분리한다. 새 출력 폴더로 아래 서버를 실행하고 해당 서버의 `/studies`를 전용 세션에서 연 다음 `tests/browser_recovery_workflow.js`를 실행한다. 검사가 끝나면 이 테스트 서버를 종료한다.

```bash
python tests/serve_review.py output/study_new_recovery_fixture --port 8740
```

## 남은 검증 범위

- 실제 저장고 ClO₂ 실행 연결, 실험 농도곡선 비교 및 물성 확정은 별도 개발·검증이 필요하다.
- GPU 실제 계산, 새 PC 최초 설치, 대규모 장시간 액침·저장고 재계산은 이번 UX 검사에서 수행하지 않았다.
- 기존 Raw 삭제·이동·압축 등 데이터 변경 작업은 실제 자료로 시험하지 않았다.
- Study 대기열과 기존 Studio 계산 사이의 PC 전체 자원 배분은 아직 통합되지 않았다.
- 중단 확인은 운영자의 실제 정지 확인을 요구한다. 앱 소유권 잠금이 없다는 것만으로 외부 솔버 정지가 증명되지는 않는다.
- 모바일 검토는 연구 화면과 추적자 Viewer에 한정한다. 모든 기존 설정 대화상자·내보내기 조합을 검사한 것은 아니다.
