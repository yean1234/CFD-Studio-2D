# Viewer 검토

- 기준일: 2026-09-28
- 대상: 기존 Studio Viewer, 프로젝트별 실행 전환
- 새 CFD 계산: 수행하지 않음
- 사용 데이터: 보존된 저장고·정규화 시험·이중액침 결과

## 변경

| 항목 | 반영 |
|---|---|
| 상단 메뉴 | 실험 묶음 이동 버튼 제거, CFD·Viewer 유지 |
| 실행 관리 | 프로젝트 안의 실행 목록 유지, 기존 Study 기록 보존 |
| 3D 화면 | 기존 이중액침 WebGL 캔버스 공유 |
| 공통 조작 | 시간 막대·재생·배속·레이어·그래프·Export 공유 |
| 저장고 표시 | 형상·물리량·단위·조회 항목을 공통 화면에 연결 |
| 애니메이션 | 저장 프레임 사이 농도·온도·유속 선형 보간 |
| 흐름 마커 | 기존 유속 화살표·이동 마커 표현 사용, 방향 표시용 |
| 확대·축소 | 모델 크기에 비례한 범위, 휠 이벤트당 최대 약 3% 변화 |
| 설정 | 실행 전 편집·저장·불러오기, 실행 후 원본 조회 유지 |
| 내보내기 | 공통 영상·화면·그래프 저장, 저장고 프레임 CSV 추가 |

- 별도 저장고 캔버스·Three.js 화면 제거
- 오른쪽 패널 폭 240px 유지, 조회·원본 경로는 패널 내부에서 스크롤
- 결과 전환 시 이전 요청 취소, 새 실행의 설정으로 형상 준비
- 실행 정보 로딩 중 Viewer 선택: 로딩 완료 후 자동 진입
- 모델 전환 시 레이어·색상 범례 복원
- 영상 파일명: 전체 계산 구간을 녹화 구간으로 오인하지 않도록 구간 표기 제거
- 원본 계산값·물성·경계조건·검증 판정: 변경 없음

## 검사

| 검사 | 결과 |
|---|---|
| Python 전체 | 122개 중 120개 통과, 환경 의존 2개 건너뜀 |
| JavaScript | 40개 통과 |
| 실제 화면 전환 | 저장고 → 정규화 시험 → 이중액침 통과 |
| 공유 캔버스 | 세 모델 모두 `gl`, 추가 결과 캔버스 없음 |
| 렌더링 | 전환 후 애니메이션 루프 유지, WebGL 오류 0 |
| 정규화 결과 | 11프레임 읽기·표시 확인 |
| 이중액침 | 5,250프레임 목록·첫 프레임 표시 확인 |
| 저장고 | 119,040셀, 6프레임, 300초 표시·재생 확인 |
| 재생 | 8×에서 저장 프레임 사이 물리시간 연속 증가 확인 |
| 휠 | -120 입력 시 거리 비율 0.97045, 급격한 확대 없음 |
| 위치 조회 | 39·12.5·3 m, 270초 조회와 원본 경로 확인 |
| CSV | 23,808행의 좌표·농도·온도·속도 성분 모두 프레임 API와 일치 |
| PNG·WebM | 실제 파일 저장 확인, WebM은 중간 종료한 짧은 녹화 |
| 원본 보존 | 기존 결과 545파일 및 이중액침 표본 5파일 SHA-256 일치 |

- 화면 전환 중 발견한 렌더링 중단과 조회 패널 넘침 수정 후 재확인
- 다운로드 검사: 테스트용 브라우저에서 기본 다운로드 경로 사용
- 독립 실험 검증·격자 수렴 판정: 이번 UI 검사의 범위에 포함하지 않음
- 건너뛴 Python 검사는 전체 검사 로그에 기록

## 재현

```text
python -m unittest discover -s tests
node --test tests/test_viewer_review.js tests/test_settings_editor.js tests/test_shared_warehouse_viewer.js
```

- `실행.bat` → 식량창고 → 실행 선택 → Viewer
- 재생·배속·단면·물리량 선택·휠·위치 조회 확인
- 실행 선택에서 정규화 결과 선택 → 이중액침 프로젝트 선택
- 동일한 화면 구성·재생 조작·정상 렌더링 확인
- Export → PNG·프레임 CSV·짧은 영상 저장
