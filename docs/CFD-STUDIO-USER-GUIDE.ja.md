# 使用方法

- CFD Studio V1.0 · エージェントインターフェース v1.4
- [한국어](CFD-STUDIO-USER-GUIDE.md) · [English](CFD-STUDIO-USER-GUIDE.en.md)
- AIエージェントの操作負担を減らし、ユーザーが同じ画面で確認できるOpenFOAM CFDインターフェース

## 起動

1. リポジトリー全体をダウンロード
2. WSL2 Ubuntuとユーザーアカウントを準備
3. 初回は`cfd_studio/설치.bat`を実行
4. `cfd_studio/실행.bat`を実行し、Studioをブラウザーで開く

- Windows 10/11 x64対応 · macOS非対応
- Windows Pythonは同梱、WSL本体・専用ソルバーのビルド・GPU設定は別途準備
- [インストール詳細](../cfd_studio/README.md) · 既存の計算フォルダーを保持

## CFD

1. **新規プロジェクト**：名前・保存先・説明・CFD Template・任意のプリセットを指定
2. **Config入力**：必須値を入力し、形状を確認してプロジェクトを保存
3. **+ CFD Case**：名前・独立したConfig・終了条件・目標を入力してCaseを保存
4. Caseを選択 → **キューに追加 → キュー開始**
5. Config差分・終了条件・状態・ログ・結果準備状況を確認
6. 結果の状態に応じて**生成 / 更新 / 開く**を選択

- **プロジェクトを検索**で既存Studioフォルダーを検証して登録
- プロジェクト内のCaseは独立、既定プリセット変更は今後追加するCaseに適用
- 失敗時はキュー停止、原因を確認して再試行またはスキップ
- キューの一時停止は次の計算から適用、実行中Caseの停止は別操作
- 再起動後は記録・キューを復元し、次の実行は一時停止状態

## CFD TemplateとConfig

- **CFD Templateリスト → +**：アンケート → 推奨ソルバー確認 → 選択 → 書式生成
- Templateはソルバー・入力書式・初期形状を定義、作成だけでは実行アダプターは追加されない
- **インストール確認**は実行ファイルの有無を確認、Studioとの実行接続とは別
- 左にConfig入力、中央に3D形状、JSON選択時は右に編集領域
- 要素・ネームタグを選択し、名前・役割・固体/液体/気体・変換・物性を入力
- **+ 属性 → 属性の種類**：状態とソルバーに応じた分類別候補を表示
- 数値・XYZベクトル・温度依存物性表は専用入力欄を使用
- 独自属性名はダブルクリックで変更、Enterまたはフォーカス移動で反映、Escで取消
- 基本項目の名前・型は固定、入力値は編集可能
- **格子**で基本間隔と局所細分化を定義、計算反映は格子アダプターの対応範囲による
- **JSONインポート / エクスポート**：値と表示書式を保存、生成済みTemplate JSONを編集の基準に使用
- **JSONを保存**は下書きへの反映、Config・Caseの最終保存は別操作
- **プリセットに保存**は初期状態で無効、有効時は別名で新規保存
- 開始済みCaseの入力は閲覧専用、変更時は**このConfigで新規Case**を使用

## 終了条件

- 指定物理時間または完全保存されたフレーム数を選択、初期フレームを含めるか確認
- 収束終了は継続判定に対応した実行接続まで利用不可
- ソルバー時間刻み・結果保存間隔・再生速度・終了条件は別設定

## Viewer

- 左のCase一覧で1件選択、円形矢印で可視化データを更新
- ゲージは可視化準備状況、物理的収束を示すものではない
- **3D Virtual**：物理量・レイヤー・断面を選択、ドラッグで回転、ホイールで拡大縮小、ダブルクリックで視点初期化
- 時間バーで保存時刻・再生・速度を操作、Exportで動画・画像を出力
- **Data Sheet**左側：全体平均または指定座標の時系列、最大3つの物理量とグラフ形式
- 右側：保存フレームの線上プロファイル、始点・終点・標本数を指定
- グラフのクリック・ドラッグで表示時点のX/Yを確認
- Data Sheet Exportはグラフ画像・CSV、Case全体のCSV出力はCFD画面
- 線上値は保存格子の標本から取得、アニメーション補間は新しいCFD結果ではない

## AIエージェント協働

- 外部エージェントに[ガイド](CFD-STUDIO-AGENT-GUIDE.ja.md)と作業内容を渡す
- エージェント専用命令で有効化したときのみ **外部エージェント操作中** と停止ボタンを表示
- **エージェント操作を停止**: 関連UI非表示、次の命令を遮断、停止信号を通知
- 人向け開始・再開ボタンはなし · 続行はエージェントとの会話で新しく指示
- 実行中CFDは継続 · Config確認・保存・計算は別操作

## エラーと保存

- エラーはコード・該当項目・詳細・対処を表示、問い合わせ時はコードを保持
- **プロジェクト管理**で保存先を確認、設定・Case・結果・キャッシュはプロジェクトに保存
- 移動時は元データを保持、実行中は保存先変更不可
- ユーザープロジェクト・結果・キャッシュ・PC設定はGit公開対象外
- [説明書](CFD-STUDIO-MANUAL.ja.md) · [JSON規約](CONFIG-JSON.md) · [エラー辞書](config-error-codes.json)

## 形状ごとの細分化

- **格子 → 局所細分化 → 形状を選択 → 形状から追加**で対象を選び、細かい格子間隔を入力。座標範囲の直接指定には **+ 領域** を使用。形状参照は現在の寸法を使用し、球と円柱は外接直方体を使用。液浸と整列した倉庫格子に対応。サイロ等価モデルは接続面を一致させるため、指定高さ区間と水平断面全体を細分化。原論文のダクト形状や汎用ソルバー接続の追加ではありません。既存結果は変更されません。
- [Mesh refinement](MESH-REFINEMENT.md)

## 個別メッシュサイズと形状フォルダー

- 形状選択 → **個別メッシュサイズ → 使用** → 間隔を入力
- **+ 局所メッシュ定義**で透明な細分化範囲を追加 · 材料・壁・物性は生成しない
- 完全包含では内側を優先 · 同一範囲・部分交差で異なる間隔は競合表示
- 現在の接続格子生成器は内側を粗くする指定をMESH-R007で拒否
- **+ フォルダー** → 名前 → 追加 · 各形状の**フォルダー**で所属を選択
- 見出しクリックで開閉 · ダブルクリックで名前変更 · ×はフォルダーのみ削除
- 保存時に所属と開閉状態を保持 · 既存結果は変更しない
- [Mesh refinement](MESH-REFINEMENT.md)

## 実行形式と結果確認

- 新規CFD Templateでソルバーを選択後、**実行形式**で接続済み入力形式を明示的に選択
- 汎用形式は既定で実行未接続 · ソルバーのインストールだけでは実行できない
- 実行形式の選択でConfig構造が変わるため、編集前に選択し保存前にJSONを確認
- サイロ等価モデルのプレビューは円筒領域と多孔質領域を表示 · 詳細ダクト・給気開口・計算格子は非表示
- カスタムサイロ寸法は最適化候補一覧に限定しない · 原案と最適案は別途検証
- 初期フレーム除外を可視化変換にも適用 · 明示的な設定のない既存結果は従来の範囲を維持

- 保存セル中心（`C`）と表示格子が一致する場合、空の区画を平均から除外し、実際のゼロ値は保持
- 点・線上の照会はデータのある最近接表示格子を使用し、元のCFDセル値・体積平均・空間補間とは区別
- 一致するセル中心がない旧形式は従来の表示格子照会を維持し、空区画の判別は保証しない
