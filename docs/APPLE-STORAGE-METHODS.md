# 연구 기반 격자 전이

[한국어](APPLE-STORAGE-METHODS.md) · [English](APPLE-STORAGE-METHODS.en.md) · [日本語](APPLE-STORAGE-METHODS.ja.md)

## 선행연구

- 2024년 논문 Methods: 대칭 절반, 균질 다공성 상자, 벽 근처 세밀화·성장비 1.2, 격자 독립성 검사 사용
- 2025년 후속 논문 Materials and methods: 대칭 절반을 사용해 팔레트 높이 영향 비교
- 두 논문은 사과 냉각 연구 · 포대형 곡물 훈증의 물성·반응·농도 검증 자료로 전용하지 않음

- [Alexander, Jakhar & Dasgupta (2024), Scientific Reports 14, 25402](https://doi.org/10.1038/s41598-024-76385-y)
- [Alexander, Jakhar & Dasgupta (2025), Scientific Reports 15, 11534](https://doi.org/10.1038/s41598-025-95886-y)

## 구현

- Config → 격자 → **축 구간 간격비 한도** · 1보다 큰 값 입력, 빈칸은 해제
- 큰 셀 쪽 구간의 셀 수를 늘려 인접 기준 간격비를 제한 · 전체 영역과 대칭 절반에 적용 · 기존 미세 간격은 거칠게 변경하지 않음
- **격자 계획 확인**에서 셀 수와 X/Y/Z 기준 간격비 확인 · 간격비를 낮추면 셀 수와 계산 비용이 증가할 수 있음
- 지붕 Z는 최대 층 높이 기준 · 모든 실제 3D 이웃 셀의 성장비·벽 경계층·y+를 보장하지 않음
- 실제 격자 좌표는 16자리 정밀도로 저장 · 검사 허용오차 유지 · 기존 Case 입력은 자동 변경하지 않음

```json
{"porous_mesh": {"max_axis_spacing_ratio": 1.2}}
```

- 기존 Template 내보내기에 병합할 부분 예시 · 새 전체 Config로 사용하지 않음 · 1.2는 검토용 예시이며 곡물 저장고의 검증된 기본값이 아님

## 범위

- 논문의 격자 생성기를 복제한 구현이 아닌 독립적인 정적 축 구간 전이 제어
- 각 블록 내부는 균일 분할 유지 · 인접 블록 간격비를 셀 수 증가로 보정 · 좌우 동시 보정으로 방향 편향 방지
- 현재 저장고는 기존 k-epsilon 모델 유지 · 논문의 SST k-omega, 벽 경계층 inflation, y+<1 제어는 이번 작업에 미연결
- 다중 스케일의 상세 포대/RVE 계산으로 저항을 산정해 전체 모델로 전달하는 자동 연결은 미구현
- AMR·독립 3D 세분화 접합·한쪽 극미세/다른 쪽 극대 셀 방식은 미구현
- MESH-R010: 잘못된 간격비 · MESH-R011: 512회 내 전이 구성 실패
- 대칭 전제와 실험 검증은 별도 확인 · 사과 물성을 기존 프로젝트에 복사하지 않음

## 검사

- 개발용 저장고 대칭 절반: 기존 930셀 → 간격비 1.2 적용 40,986셀
- 계획 기준 X/Y/Z 최대 간격비 1.150 / 1.167 / 1.188 · 셀 수·비용 감소를 보장하는 기능이 아님
- OpenFOAM v2312 checkMesh 통과 · 총 체적 8,726.25m³ 유지
- 1초·3프레임 유속/온도/농도 연결 시험 통과 · 질량수지 상대오차 약 9.16e-14
- 3cm 연구 계산·논문 재현·격자 수렴·실험 검증 완료를 의미하지 않음
