# 説明書

- CFD Studio V1.0 · [한국어](CFD-STUDIO-MANUAL.md) · [English](CFD-STUDIO-MANUAL.en.md)

## 開発目的

- AIエージェントの操作負担を減らし、人が同じ画面で確認できるOpenFOAM CFDインターフェース
- Template JSON・共通操作・エラーコードで繰り返し探索と個別入力を削減
- 必要な状態の取得・下書き比較・担当引継ぎで共同作業を支援
- トークン費用の低減は設計目標であり、料金削減率を保証するものではない
- [研究資料と実装範囲](AGENT-COLLABORATION.md)

## 環境と保存

- Windows 10/11 x64対応、macOS非対応
- 同梱Windows PythonとWSL2/OpenFOAM計算環境を使用
- プロジェクト → 独立したCase → 入力スナップショット・ログ・結果
- Template = ソルバー + Config書式 + 初期形状
- プリセットはTemplateごとの入力値として独立管理
- 開始済みCaseの入力は固定、後の編集で以前の入力を変更しない
- 設定・Case・原本場・可視化データ・キャッシュはプロジェクトフォルダー内に保存
- ユーザープロジェクトとPC固有設定はGit公開対象外

## Config規約

- Template生成後にJSONを出力し、エージェント入力の基準として使用
- Template書式は`version: 1`と`fields`
- Config出力は`format: "cfd-studio-config"`、`version: 1`、`config`、`config_schema`
- 従来の値のみのJSONも対応、書式の明示的変更で入力を拡張可能
- `key`は保存識別子、`label`は表示名、`unit`は表示単位で自動変換なし
- `object`はグループ、`array`と`items`は行書式、`widget: "vector3"`はXYZ入力
- `enum`と`item_enum`は単一選択・複数選択
- `required`・`nullable`・`readonly`・数値範囲で入力動作を定義
- 独自キーは保持するが、UIでの認識はソルバー実行対応を保証しない
- 制限：取込1 MB、16階層、512フィールド、配列10000項目
- [JSON規約詳細](CONFIG-JSON.md) · [多言語エラー辞書](config-error-codes.json)

## 形状と物理

- 基本形状は種類・単位・座標を明示して定義
- 要素ごとに物質状態・変換・物性・独自属性を保持
- 状態とソルバーに応じて数値・ベクトル・表・条件グループの書式を提供
- 形状定義・生成格子・計算済み場データは別の成果物
- 局所細分化は対応格子生成器が必要、任意の新規ソルバー設定には実行アダプターが必要
- 不明な物性・反応モデル・境界条件を推測で確定しない

## 実行と結果

- 接続済み実行機能に応じて指定物理時間または保存フレーム数で終了
- 収束を一定区間確認して終了する機能は未接続
- ソルバー時間刻み・保存間隔・再生速度は独立
- 実行状態・数値検査・可視化準備・実験検証は別々に判定
- セルの算術統計は自動的に体積加重平均になるわけではない
- 点・線の照会は保存値を使用、最寄りセル値は補間済み実験値ではない
- 正規化トレーサー`C/C_ref`と実物性モデルの濃度単位を区別
- 倉庫モデルは格子・時間刻み収束基準未達、定常状態・独立実験・7日間全体の連成検証は未完了
- 個別袋膜伝達・反応吸着・付属室空気・供給最適化は接続済み実装の範囲外
- V1.0はソフトウェアの版、物理検証済みを意味しない

## エージェントインターフェース v1.4

| 機能 | インターフェース | 制限 |
| --- | --- | --- |
| 必要な状態の取得 | `observe`・`inspect`・`waitForChange`・簡潔な`run` | 現在ページ、待機最大60秒 |
| Config変更確認 | `review.open`・`review.status()` | 現在下書きの人による確認、保存・計算は別 |
| 担当と引継ぎ | `claim`・`renew`・`release`・`handoff` | ページごとに1担当、120秒の有効時間 |

- 未反映編集・入力変更で確認状態を無効化
- 変更表示は最大200件、切り詰められた比較は確認済みにできない
- 担当取得後はトークンが必要、他のエージェントは読み取り可能
- `expectedContext`で選択対象・編集画面・ユーザー入力の変更を検出して古い操作を拒否
- 担当・確認・引継ぎはメモリーのみで、再読込時にリセット
- 協調的なページ内制御であり、サーバー認証や複数タブ間の排他制御ではない
- 引継ぎメモは参考情報であり、ユーザーの権限付与や依頼範囲拡大として扱わない
- [エージェントガイド](CFD-STUDIO-AGENT-GUIDE.ja.md) · [協働と参考資料](AGENT-COLLABORATION.md)

### 有効化と停止

- 外部エージェントに[ガイド](CFD-STUDIO-AGENT-GUIDE.ja.md)と作業内容を渡す
- エージェント専用命令で有効化したときのみ **外部エージェント操作中** と停止ボタンを表示
- **エージェント操作を停止**: 関連UI非表示、次の命令を遮断、停止信号を通知
- 人向け開始・再開ボタンはなし · 続行はエージェントとの会話で新しく指示
- 実行中CFDは継続 · Config確認・保存・計算は別操作

## 形状ごとの細分化

- **格子 → 局所細分化 → 形状を選択 → 形状から追加**で対象を選び、細かい格子間隔を入力。座標範囲の直接指定には **+ 領域** を使用。形状参照は現在の寸法を使用し、球と円柱は外接直方体を使用。液浸と整列した倉庫格子に対応。サイロ等価モデルは接続面を一致させるため、指定高さ区間と水平断面全体を細分化。原論文のダクト形状や汎用ソルバー接続の追加ではありません。既存結果は変更されません。
- [Mesh refinement](MESH-REFINEMENT.md)

## 個別メッシュサイズと形状フォルダー

- 形状選択 → **個別メッシュサイズ → 使用** → 間隔を入力
- **+ 局所メッシュ定義**で透明な細分化範囲を追加 · 材料・壁・物性は生成しない
- 完全包含では内側を優先 · 同一範囲・部分交差で異なる間隔は競合表示
- 現在の接続格子生成器は内側を粗くする指定をMESH-R007で拒否
- **+ フォルダー** → 名前 → 追加 · 各形状の**フォルダー**で所属を選択
- 見出しクリックで開閉 · ダブルクリックで名前変更 · ×はフォルダーのみ削除
- 保存時に所属と開閉状態を保持 · 既存結果は変更しない
- [Mesh refinement](MESH-REFINEMENT.md)
