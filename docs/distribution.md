# 배포

- CFD Studio **V1.0**
- 배포 브랜치: `main` · 버전 태그: `v1.0`
- 지원 운영체제: Windows 10/11 x64 · macOS 미지원

## 포함

- Studio·3D Virtual Viewer·Data Sheet Viewer
- 배포용 CFD Template·공개 Config 예제·케이스 생성기·결과 변환 도구
- `설치.bat`·`실행.bat`·Windows Python 3.12.10 x64 embedded runtime
- 사용자 문서·한국어/영어/일본어 에이전트 안내·검사 코드
- 별도 연구·GPU 개발 도구 · 일반 실행 지원과 개발 기능은 설명서에서 구분

## 제외

- 사용자 프로젝트·실행 이력·Raw·계산 결과·영상·캐시
- 개인 프리셋 등록부·UI 상태·PC별 환경 설정
- 협력기관 원자료·비공개 실험 자료
- 공개 예제와 문서용 이미지는 사용자 프로젝트 폴더와 구분하여 포함

## 설치와 업데이트

- 최초 설치: [설치 안내](../cfd_studio/README.md)에 따라 WSL2 준비 → `설치.bat` → `실행.bat`
- 기존 사용자는 계산 종료·대기열 상태를 확인한 후 Studio를 정상 종료하고 프로그램 업데이트
- 기존 프로젝트 폴더·등록부·프리셋·`studio_config.json` 보존
- `설치.bat`은 기존 계산 폴더가 있으면 보호를 위해 중단 · 폴더 삭제로 우회하지 않음
- 프로젝트 형식이 유지된 폴더는 **프로젝트 찾기**로 다시 등록 가능
- Git 추적 제외는 로컬 파일 삭제를 뜻하지 않음

## 검증

- V1.0 검사 결과: [릴리스 노트](RELEASE-NOTES.md)
- 프로그램 검사는 설치파일·입력·보관·결과 읽기·화면 동작 범위
- 새 PC의 전체 설치·장시간 계산·GPU 환경별 검증은 별도
- 이번 배포 확인에서 새 CFD 계산을 수행하지 않음
- 버전 번호는 격자·시간간격 수렴, 물성의 타당성, 독립 실험 검증을 보증하지 않음
- 날짜가 있는 이전 검토 문서는 해당 시점의 기록 · 현재 조작은 [사용법](CFD-STUDIO-USER-GUIDE.md) 기준
