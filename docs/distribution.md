# 소프트웨어 배포 노트

## 포함한 구성

v174 앱과 Viewer, Raw 변환 도구, 액침냉각·저장고 케이스 생성기, CPU/GPU 선택 및 GPU 개발 런타임 설치·검증 도구, 설계 실험 생성 도구, 기본 설정 2종, Python 3.12.10 Windows embedded 런타임을 포함합니다.

## 배포 정리에서 수정한 부분

- 기존 설치 배치가 존재하지 않는 `_runtime/setup_bridge.py`를 참조하던 문제를 수정하고 실제 브리지를 배포 소스로 추가했습니다.
- 브리지는 한글·공백 경로를 UTF-8/base64로 전달하고 Ubuntu 터미널의 sudo 입력을 유지합니다.
- 설치 시 기존 WSL 케이스를 덮어쓰지 않도록 차단합니다. 고유한 새 케이스 경로를 지정해야 합니다.
- 검증 기준인 OpenCFD v2312를 설치에서 선택하며 필수 솔버 누락은 실패로 처리합니다.
- 개인 환경 설정·실행 상태·결과 데이터·대용량 설치 파일은 Git 추적에서 제외합니다. 설치에 필요한 embedded Python만 포함했습니다.
- 원본 개발 폴더와 계산 결과는 유지하고, 배포용 작업 폴더에서만 위 항목을 수정했습니다.

## 확인 범위

Python 구문, Windows embedded 런타임 기동, 필수 배포 파일, 한글·공백 경로의 셸 구문, 기존 케이스 보호, 두 기본 설정의 생성기 검사를 수행합니다. 새 PC의 WSL 설치부터 장시간 솔버 실행·GPU 빌드까지 전체 설치시험을 대신하지 않습니다.

사용법은 Git 배포본 기준으로 설치, 설정, 계산, 시각화, 데이터 보존, 문제 해결 순서로 정리했습니다. 설정의 물리 가정은 프로젝트별로 검토하세요. 이 저장소에는 저자의 실제 실험 데이터와 협력랩 발표자료를 포함하지 않습니다.

## 사용법 점검 후 보완

- WSL 자체 설치와 OpenFOAM 설치를 구분하고, 배포하지 않는 설치 EXE·디스크 정리 도구 안내를 제거했습니다.
- 앱을 설치 배치보다 먼저 열어도 설치 예제와 동일한 케이스 경로·배포판·자동 재개 기본값을 사용하도록 맞췄습니다.
- 새 Ubuntu에 curl이 없을 때 설치하고, 패키지 목록 갱신 실패를 명시적으로 처리합니다. 중첩된 케이스 경로의 상위 폴더도 준비합니다.
- 정상해석의 반복 번호와 Viewer 재생 시간을 물리 초와 구분했습니다. CPU 배정 비율을 시스템 전체 사용률 보장으로 표현하지 않습니다.
- 기본값 일치 회귀 검사와 셸 구문 검사를 추가했습니다. 실제 새 PC 전체 설치·솔버 계산·GPU 실행 및 브라우저 시각화의 종단 검증은 수행하지 않았습니다.
