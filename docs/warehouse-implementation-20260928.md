# 저장고 구현 진행과 검증 경계 (2026-09-28)

기준 저장소는 원래 Git 연결 폴더 `CFD-Studio`이다. 기존 `cfd_studio/Project`, Raw, 설정과 과거 계산 결과는 수정하지 않았다. 앞선 미커밋 결과 무결성·격자 검사 코드를 검토해 보존하고, 별도 개발 브랜치의 저장동 수송 시험 코드를 같은 저장소에 통합했다.

## 현재 완료와 미완료

| 항목 | 현재 판정 |
|---|---|
| 78 m 저장동 공칭 외형 격자 | OpenFOAM `checkMesh` 통과. 실내 순치수·5 m 부속실·최종 적재 배치가 포함된 확정 해석 영역은 아님 |
| 박공지붕 격자와 수송 솔버 | 별도 CLI 경로에서 연결. 정지 공기·폐쇄벽 정규화 수치시험 통과 |
| ClO₂ 기상 입력 | 별도 CLI 경로에 문헌 공기 확산계수와 출처 필수 반응·체적 평균 교환 항 구현. 합성 입력 시험만 있음 |
| Studio 공통 화면 | 액침냉각·단상 저장고·추적자의 모델·단위·검증 기록을 설정 화면에서 구분. 저장고 수송 계산의 별도 읽기 전용 3D 셀 중심 화면과 위치·시간 조회 연결. 액침냉각·단상 저장고의 실제 3D 결과 원본 검사는 아직 없음 |
| 선정 저장고 현장 모델 | 실내 유효 치수, 시트 구획, 포대·통로, 개구, 열·비영 유동, 실제 누출 경계가 없어 미완료 |
| 현장 검증·최적화 | 독립 센서 시계열과 보정/검증 분리가 없어 미실시. 연구 설계 화면은 후보·제약 미리보기이며 검증된 CFD 최적화가 아님 |

ClO₂ 공기 중 확산 입력의 5/23/40 °C 값은 [Lee et al. (2015)](https://doi.org/10.1016/j.jfoodeng.2014.07.008)의 저자 초록에 기록된 0.129/0.145/0.173 cm²/s를 SI로 변환한 것이다. 논문의 실험실 조건과 포대식 쌀 저장고의 표면 반응·누출·적재 전달은 구별한다. 반응·교환 계수나 독립 실측을 자동으로 채우지 않는다.

## 이번 원래 저장소 실행

OpenFOAM v2312 환경에서 `tracer_transport/solver`를 `wmake`로 빌드하고 다음 명령을 새 출력 폴더에 실행했다. 해당 결과는 정규화 수치시험이며 ClO₂ 현장 계산이 아니다.

```bash
source /usr/lib/openfoam/openfoam2312/etc/bashrc
python3 -m tracer_transport.warehouse_case \
  --config tracer_transport/warehouse_gable_verification.json \
  --output output/warehouse_transport_20260928_01
python3 -m tracer_transport.verify_gable_convergence \
  --config tracer_transport/warehouse_gable_verification.json \
  --max-cells 200000 \
  --output output/warehouse_transport_20260928_convergence_verified
python3 tests/audit_warehouse_case.py output/warehouse_transport_20260928_01
```

- 기준 계산: 22,308셀, 11프레임, 해석해 RMSE `5.3339e-6`, 상대 질량수지 오차 `6.2535e-16`, 음수 농도 없음.
- 격자만 세분화: 2,340 → 22,308 → 178,464셀, 시간간격 0.1 s 고정. RMSE `3.5080e-6 → 1.2204e-6 → 6.4836e-7`.
- 시간간격만 세분화: 22,308셀 고정, 2 → 1 → 0.5 s. RMSE `9.8952e-6 → 5.3339e-6 → 3.0496e-6`.
- 원본 대조: OpenFOAM `C` 장 11개와 NPZ의 245,388개 값 최대 차이 0. 농도 시간 적분의 재계산 차이 0. 검사기는 원본 파일의 SHA-256도 보고한다.

이 세 검사는 공칭 외형·정지 공기·폐쇄벽·정규화 확산 해석의 보존과 수렴 경향을 확인한다. 독립 유동장, 포대 전달, 실제 누출, 실측 온도·농도와의 일치는 확인하지 않는다. 이후 추가된 저장고 결과 화면은 선택 프레임의 원본 `C`와 조회 배열을 일치 검사하고 최대 25,000개 셀 중심 농도를 색 점으로 표시한다. 브라우저에서 정규화 기준 결과의 모델·단위·검증 상태, 3D 점 표시와 위치 조회를 확인했다. 셀 체적 렌더링이나 물리 검증의 근거로 삼지 않는다.

## 자료와 연결의 다음 관문

도면의 83 m 전체는 78 m 저장동과 5 m 부속 공간이다. 표준 예시 도면은 해당 시설의 실내 순치수·벽 두께·최종 적재 배치·시트 구획 개구를 제공하지 않는다. 따라서 확정 형상으로 바꾸려면 실내 치수와 시트 구획 경계, 포대·팔레트·통로, 급배기·문·팬·누출 위치의 근거가 필요하다. 온습도 및 운전 기록, 센서 좌표·시계열·불확도, 보정/독립 검증 분리 자료가 있어야 실제 물성 보정과 실험 검증을 판정할 수 있다.

현재 저장된 Studio 프로젝트 13개는 모두 정규화 `gas_transport` 결과다. 기존 액침냉각·단상 저장고의 읽기·저장·3D 표시를 실제 결과로 점검하려면 해당 유형의 보존된 원본 결과 또는 별도 검증용 실제 실행이 필요하다. 새로운 합성 UI 시험은 원본 CFD 검증으로 집계하지 않는다.
