## 기록의 신뢰도

- **구현**: 코드 경로 확인 · 모든 환경에서 검증됐다는 뜻은 아님
- **부분 구현**: 제한된 실행기·데이터 형식에서만 연결
- **미구현**: 필요한 동작 연결 없음
- **미검증**: 적용 근거나 테스트 증거가 아직 충분하지 않음
- **제안**: 향후 설계 · 현재 동작으로 안내하지 않음
- 과거 날짜 문서는 그 시점의 기록 · 최신 코드와 다르면 현재 코드·계약을 검토하고 최신 문서를 수정
- 개별 검사 숫자는 수행 시점과 대상에만 유효 · 개발 문서 작성이 전체 CFD 검증 완료를 의미하지 않음

## 유지 규칙

- 코드 변경과 문서 변경을 같은 검토 단위로 제출
- 계약·상태·오류 코드·언어별 안내·미완료 항목을 함께 확인
- 신규 요구사항에 ID 부여 · 삭제 대신 상태와 대체 항목 기록
- 문서 완전성은 아래 검사와 검토표로 관리 · 자동 검사만으로 의미상 누락이 없다고 단정하지 않음
