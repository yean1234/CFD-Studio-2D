# ADR-001 Case 독립성

- 상태: 현재 설계 회고 · 2026-10-05 · 코드 기준 e861572
- 문제: 프로젝트 설정 수정이 이전 계산/다른 Case를 바꾸면 재현과 비교가 불가능
- 선택: 프로젝트는 묶음·기본값 참조, Case는 독립 입력, Attempt는 실행 스냅샷과 결과
- 대안: 프로젝트의 단일 Config를 모든 실행이 공유 · 원본 프리셋 직접 편집
- 영향: 저장/복구 로직은 복잡해지지만 입력과 결과의 이력 추적 가능
- 제한: 기존 결과 경로와 새 프로젝트 저장 구조가 공존
- 근거: [데이터 계약](../DATA-CONTRACTS.md), [실행 상태](../RUNTIME-API.md), REQ-001~003
