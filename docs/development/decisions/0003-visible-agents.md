# ADR-003 외부 에이전트의 가시적 조작

- 상태: 현재 설계 회고 · 2026-10-05 · 코드 기준 e861572
- 문제: 직접 파일/백엔드 수정만으로 사용자가 진행·입력·오류를 확인하기 어려움
- 선택: 공개 화면 명령과 JSON 초안 입력을 사용하고, 개발 작업은 진행 CLI로 표시
- 대안: 앱에 내장된 에이전트처럼 보이는 사용자 시작 버튼 · 화면 없는 숨은 조작
- 영향: 사용자는 같은 초안을 확인하고 중단 가능, 에이전트는 필요한 상태만 조회
- 제한: 중단은 외부 LLM/이미 실행 중인 솔버를 강제 종료하지 않음 · 에이전트가 신호를 준수해야 함
- 근거: [에이전트 사용법](../../CFD-STUDIO-AGENT-GUIDE.md), REQ-019~021
