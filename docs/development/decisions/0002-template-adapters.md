# ADR-002 Template와 실행 어댑터

- 상태: 현재 설계 회고 · 2026-10-05 · 코드 기준 e861572
- 문제: 새 FORM/Template 이름이나 솔버 설치만으로 임의 해석이 가능한 것처럼 보일 수 있음
- 선택: 솔버 정의·Config 스키마·설치 확인·실행 어댑터·결과 변환의 상태를 분리
- 대안: 프로젝트명별 전용 화면 또는 등록 솔버 전체를 실행 가능으로 표시
- 영향: 동일 UI에서 사용자 JSON 확장을 수용하되 계산에 연결되지 않은 속성을 명시해야 함
- 제한: 현재 전용 Config 호환 규칙이 남아 있고 모든 속성이 실행기에 연결된 것은 아님
- 근거: [구조](../ARCHITECTURE.md), [Config 규칙](../../CONFIG-JSON.md), REQ-004~007
