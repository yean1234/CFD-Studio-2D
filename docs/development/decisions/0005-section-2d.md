# ADR-005 액침 수조 2D 단면과 3D→2D 스케일링

- 상태: 제안 · 사용자 요청으로 구현 · 연구팀 검토 대기 · 2026-10-05 · 코드 기준 c56c6d4 이후 2D 단면 변경
- 문제: 기포장 연구는 BubbleML 2D와 같은 차원의 거친 격자 입력 `(α, q″)`가 필요하나 수조 CFD는 3D만 생성
- 선택: 3D Config를 유지하고 CPU 중심 y–z 단면을 1셀 두께 empty 격자로 생성 · 기본 `local_flux`로 CPU 열유속과 발열 높이 보존 · 코일 UA는 2D 폭당 입열에 비례
- 대안: x–y 정면 단면(CPU 면이 단면에 수직이라 발열 벽 소실) · 별도 2D Config 복제(근거 이중화) · 폭 평균 열유속 기본값(국소 비등 강도 약 1/5)
- 영향: 3D 생성 결과 불변 · 셀 약 6천 개로 조건 스윕 가능 · 거친 입력 형식이 Cooper 게이트와 일치
- 제한: x 방향 유동·기포 확산 없음 · `local_flux`는 3 mm 격자 코일 상한 초과로 장시간 상단 액체 가열 · 벽면 온도는 경계 모델 값
- 향후: Viewer 2D 표시(DEV-15) · 장시간 열평형과 TMC-49 임계압 근거(DEV-16)
- 근거: [2D 단면](../../SECTION-2D.md), REQ-037
