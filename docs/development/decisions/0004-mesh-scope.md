# ADR-004 격자 기능 범위

- 상태: 현재 설계 회고 · 2026-10-05 · 코드 기준 e861572
- 문제: 문헌의 대칭·성장비와 정적 전이·AMR이 혼동될 수 있음
- 선택: 대칭 절반·최대 변 길이·정적 축 전이를 개별 입력과 검증 범위로 제공
- 대안: 예산 초과 시 몰래 조대화 · 문헌 AMR 구현으로 일괄 표시
- 영향: 설정 보존·셀 수 사전 검사 가능, 전이가 셀 수를 늘릴 수 있음을 안내
- 제한: 모든 3D 이웃 셀 성장비·벽층·y+·동적 격자 미보장
- 향후: [경계층·AMR 제안](../MESH-ROADMAP.md)을 별도 ADR로 검토
- 근거: [연구 기반 기능](../../APPLE-STORAGE-METHODS.md), REQ-024~029
