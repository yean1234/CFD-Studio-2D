# 인터페이스 계약

- 상태: 기존 요구사항을 정리한 유지·인수 기준 · 모든 항목의 실제 화면 재검증 완료 선언이 아님
- 연결: REQ-005~007, REQ-012~022 · 현재 화면과 다르면 결함/제한을 기록
- 기준 코드: `form_config_editor.js`, `spatial_editor.js`, `execution_workspace.js`, `viewer_presentation.js`, `data_sheet_viewer.js`

## 공통

- 프로젝트 이름으로 화면 배치/목록/조작을 바꾸지 않음 · 입력 양식과 결과 요소는 Template/솔버/메타데이터로 결정
- CFD와 Viewer의 프로젝트·Case 선택 맥락 유지 · Case가 하나여도 동일 목록 구조
- 버튼 아이콘 중앙 정렬·일관된 크기·선택 테두리·토글 방향 표시
- 프로젝트/Template 목록의 높이·스크롤·항목 폭 일관성
- CFD/그래프의 좌우 블록 높이 일치 · 그래프 내부 크기와 배경 블록 크기는 별도 조정
- 한국어·영어·일본어 전환 · 사용자 프로젝트명/Template명/입력값은 번역하지 않음
- 일반 UI의 우발적 텍스트 드래그 방지 · 입력값/상세 수치 복사는 허용
- 주요 필드/버튼이 줄바꿈·말줄임 때문에 식별 불가능하지 않도록 검토
- 공식 용어 사용 · 내부 작업 이력·불필요한 경로·개발용 설명을 기본 화면에 노출하지 않음

## 프로젝트와 Template

- CFD 상단: 프로젝트 찾기 / 새 프로젝트
- 프로젝트 찾기: 폴더 선택 → 형식 확인 → 추가 · 취소/찾기 동작에 필수값 오류를 잘못 표시하지 않음
- 프로젝트 관리의 경로 표시는 유지하되 불필요한 폴더 찾기 조작을 중복 제공하지 않음
- 새 프로젝트: 이름·설명·폴더·Template·해당 Template의 프리셋
- Template 필드의 +는 기존 생성 UI를 연결 · 초안 손실 없이 생성 후 복귀
- Template 생성: 설문 → 추천/선택 솔버 → 양식 → 초기 공간 정의
- 여기에 없음/미지원 조합은 이유 표시 · Config Template 중복 선택을 다시 추가하지 않음
- CFD Template 목록의 +·수정과 사용자 속성 이름 편집을 구분

## Config

- 왼쪽 입력, 가운데/오른쪽 독립 3D 블록, JSON 열면 가장 오른쪽 독립 편집 영역
- 이름을 요소 상단에 표시 · 영역 역할은 사용자 입력 · 위치/크기·물질 상태·필수 속성 제공
- 고체/액체/기체 및 솔버에 따라 속성 후보 필터 · 사용자 추가 속성은 확장 가능
- 사용자 추가 속성 이름은 더블클릭 편집 · 기본 키/자료형은 임의 변경 금지
- 배열·좌표·물성 표는 행 추가/XYZ 입력 제공 · 원시 JSON 입력만 강제하지 않음
- 액체/기체의 채움 공간은 지원되는 형상 연결로 정의 · 액체 높이만 고정 노출하지 않음
- JSON 버튼은 전체·공간·선택 형상·주요 속성 그룹에만 배치 · 모든 하위 값에 남발하지 않음
- 요소 선택 시 스크롤 유지 · 이름표 연결선으로 형상 가림 완화
- 종료 조건·격자·계산 출력·관측·비교와 요소의 물리 속성을 분리
- 취소·저장 분리 · 프리셋 저장 기본 해제 · 입력값을 예시/가정과 혼동하지 않음
- 결과 Config는 입력형 표시를 유지하되 읽기 전용 · 변경하려면 새 Case
- 문헌 출처는 세부 설정의 마지막 분류에 배치

## CFD 실행

- + CFD Case 버튼의 크기·위치·기호 간격 유지
- 설정 차이·로그는 선택한 Case 기준 · 상태와 버튼 의미 일치
- 실패는 원인과 재시도 가능 여부, 중단은 지원되는 이어하기 표시
- 전체 CSV는 선택 Case 인터페이스에서 접근
- CPU·연결된 드라이브별 사용/전체 용량·GPU별 사용/VRAM 표시 · 없는 장치를 임의 생성하지 않음

## Viewer

- 3D Virtual / Data Sheet를 별도 선택 버튼으로 제공 · 현재 모드 표시 · 3D 버튼 왼쪽
- Case 단일 선택 · 읽기 전 준비율 유지 · 재읽기 때 실제 처리 상태를 게이지로 표시
- 준비율은 시각화 상태이며 정확도 아님 · 완료/기본/선택 색상은 기존 테마 규칙 유지
- 프로젝트·Case 이름의 위치·가독성 일관성 · 중복 상단 제목을 추가하지 않음
- 회전·확대·축소 방향과 감도 일관성 · 표시 밀도는 결과 데이터 범위에 맞게 제공
- 3D 재생바: 시간과 전체 프레임 수 · 오른쪽 Export는 영상/사진
- Data Sheet는 재생 버튼 대신 그래프 시점 선택 · 클릭/드래그 시 정확한 X/Y와 안내선
- 왼쪽: 전체 평균/특정 좌표 선택·최대 3개 변수·선/막대/산점도
- 오른쪽: 선상 프로파일 · 과거의 독립 좌표 시계열 블록 요청과 현재 구성을 혼동하지 않음
- 좌표 입력은 유효 최소/최대 범위 안내 및 범위 검사
- 그래프 Export는 이미지/CSV · 불필요한 하단 표·모델 검증 탭·중복 설명을 기본으로 추가하지 않음

## 에이전트

- 에이전트 전용 명령으로 조작 표시 활성화 · 사람이 내장 에이전트를 시작하는 버튼처럼 만들지 않음
- 최상단 진행 표시와 사용자 중단 제공 · 기존 설정/info 버튼 위치 유지
- 숨은 백엔드 조작으로 사용자 검토를 생략하지 않음
- UI 구조 변경 시 [실제 인수 시나리오](VERIFICATION.md)를 해당 범위에서 재검사
