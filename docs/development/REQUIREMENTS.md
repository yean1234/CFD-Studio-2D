# 요구사항

- 기준: `e861572` · 코드와 기존 검사 진입점을 대조한 상태
- 요구사항 ID는 기능 추적용 · 테스트가 연결되어 있어도 미구현 기능이 구현됐다는 뜻은 아님
- [기계 판독 추적표](capabilities.json)에 코드·검사 경로·완료 기준 보존
- UI 요구사항은 실제 화면 인수 검사가 추가로 필요 · 이번 문서 작업은 전체 UI 재검증이 아님

## 변경해도 유지할 규칙

- 프로젝트 → 여러 Case → 각 Attempt/결과 · 실행별 독립성
- Template·프리셋·입력값·스냅샷 구분
- 프로젝트명에 의한 UI 분기 금지 · 기존 디자인과 선택/스크롤 연속성
- 3D·그래프·CSV 값의 모델/단위/좌표/원본 추적
- 사용자 입력·원본·미커밋 변경 보존
- 실패·미지원·미검증·제외를 명확히 표시
- 에이전트가 사용자 화면에서 진행하고 중단 신호를 준수
