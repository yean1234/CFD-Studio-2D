# 격자 개발 제안

- 상태: **제안 · 미구현**
- 관련: REQ-024~030, DEV-01/02/04
- 기존 기능: 정렬 블록·국소 간격·Y 대칭·최대 변 길이·정적 축 간격 전이
- 현재 블록 내부는 `simpleGrading (1 1 1)` · AMR 결과 처리는 연결되지 않음

## 근거와 구분

- 사과 저장고 논문은 벽 근처 세밀화·성장비 1.2·SST k-ω·y+<1을 설명
- 해당 논문에서 계산 중 AMR 적용을 확인하지 못함
- 기존 축 간격비 제한은 논문의 벽 경계층 생성기 복제가 아님
- 논문의 사과 물성·팬 조건·온도 검증을 곡물 훈증에 전용하지 않음
- [원문과 OpenFOAM 기능](REFERENCES.md)

## 단계 A · 정적 벽면 층

- 제안 입력: 사용 여부, 대상 wall patch, 첫 셀 높이, 층수, 성장비, 전체 두께 한도
- `snappyHexMesh` 층 추가와 현재 정렬 블록 grading 중 형상·호환·품질·비용을 비교한 뒤 ADR로 선택
- patch별 실제 벽과 대칭면/유입출구/다공성 내부 경계를 구분
- 다공성 영역의 외곽을 임의로 no-slip 벽으로 바꾸지 않음
- 좁은 틈·층 충돌·음의 체적·층 누락·셀 한도 초과에 명확한 오류/상태 제공
- 끄면 기존 생성 경로 유지 · 켠 상태로 실패하면 조용히 층 없는 격자로 대체하지 않음
- 생성된 실제 격자에서 중심·체적·영역을 읽어 결과 계약과 일치시킴

완료 기준

- 전체/Y 절반의 동일 형상·체적·다공성 분류 유지
- 입력 층과 실제 생성 층·두께·실패 위치 확인
- checkMesh 및 원본/변환 좌표·체적 대조
- 구버전 Config·결과의 변경 없는 읽기

## 단계 B · 난류·벽 처리와 y+

- SST 선택 및 필수 초기장·경계조건·벽 함수/벽 해상 방식의 조합 검증
- 첫 셀 높이는 유동 상태에 의존 · 입력만으로 y+<1을 보장하지 않음
- 계산 후 대상 벽의 실제 y+ 분포·최대값·목표 충족 범위 보고
- 무유동/전단이 없는 시험만으로 실제 벽 경계층 성능을 검증하지 않음
- 기준 유동 문제와 저장고 작은 시험에서 속도·온도·보존성·격자 민감도 확인

## 단계 C · 동적 격자 기반

- 제안 입력: 사용 여부, 세분화 지표, 임계값, 조대화 조건, 갱신 간격, 단계/셀 수 상한
- 솔버가 동적 격자 갱신과 압력·유량 보정을 실제로 호출하도록 연결
- 셀 분할/병합 뒤 유속·열·스칼라·공극률·다공성 구역의 일관성 확인
- 총량 검사에는 적절한 체적·공극률 가중치를 사용
- 대칭 patch와 비물리 국소격자 정의 영역의 의미 유지
- 불안정한 반복 분할/병합을 막을 완충 조건과 예산 정책 명시

## 단계 D · 저장·Viewer·재개

- 프레임마다 mesh ID, 셀 수, 중심, 체적, 영역, 원본 경로 저장
- 서로 다른 격자의 배열 인덱스로 시간 보간하지 않음
- 공통 표시 격자로 투영할 경우 원본과 구분하고 오차/방법 기록
- 좌표 조회·선상 프로파일·전체 평균·CSV에서 각 시점의 실제 격자 사용
- 재시작 체크포인트에 해당 격자·필드·실행 스냅샷을 함께 보존

## 출시 게이트

- 네 단계 각각 Config→실제 실행→저장→조회 연결 확인
- 켜기/끄기·무효 입력·예산 초과·실패·재개 시험
- 세분화 전후 총량 및 고정 미세 격자 기준해와 비교
- 개선된 오차와 증가/감소한 계산 비용을 함께 기록
- 벽 경계층과 AMR은 별도 기능 상태로 공개 · 하나의 토글로 둘 다 완료라고 표시하지 않음
