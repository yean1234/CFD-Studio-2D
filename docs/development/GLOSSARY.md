# 용어

| 용어 | 의미 |
| --- | --- |
| CFD Template | 솔버·Config 양식·초기 공간 형상의 정의 |
| Preset | 특정 Template에 연결된 입력값 묶음 |
| Project | 저장 위치와 여러 Case 이력의 묶음 |
| Case | 독립 Config·종료 조건·결과를 가진 해석 단위 |
| Attempt | Case의 개별 실행 시도 · 재시도/재개 이력 |
| Snapshot | 시작 시 고정한 입력·연결 정보 |
| Adapter | Config를 실제 솔버 입력·실행·결과로 연결하는 코드 |
| Raw | 솔버가 저장한 원본장·로그 |
| Visualization readiness | 결과 읽기/변환 준비 상태 · 정확도와 별개 |
| Numerical verification | 수치해·보존성·격자/시간간격 검사 |
| Experimental validation | 독립 실측과 모델 비교 |
| y+ | 벽 거리의 무차원 지표 · 첫 셀 높이와 유동 상태에 의존 |
| Boundary-layer mesh | 벽 수직 방향의 얇은 셀 층 |
| Static refinement | 계산 전에 고정한 세분화 |
| AMR | 계산 도중 기준에 따라 격자를 세분화/조대화하는 방법 |
| ADR | 구조적으로 중요한 결정과 근거·영향 기록 |
| RFC | 구현 전 변경 제안과 검토 기록 |
| Regression | 변경으로 이전 동작이 깨지는 현상 |
| Acceptance criteria | 완료 판정에 필요한 관찰 가능한 조건 |
