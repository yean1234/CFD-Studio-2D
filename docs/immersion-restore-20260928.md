# 이중액침 복구

- 원인: 새 실행 목록에 외부 보관 폴더 연결 누락
- 원본: `D:\CFD Studio\Project\3mm_Test`
- 복구: `이중액침` 프로젝트, `3mm_Test` 실행 이력
- 식량창고: 기존 실행 27개 유지
- 이중액침: 기존 실행 1개 별도 표시
- 외부 원본 복사·이동 없음
- 조회 시 메타데이터 보정·상분율 캐시 자동 변환 제외
- 실행 설정·기포 파일·유속 파일 등 표본 5개의 SHA-256 일치
- 기포·유속·온도·상분율: 각각 5,250개 파일 확인
- Raw 폴더 보존 확인
- 실제 Viewer: 0~52.49초 재생 구간·3D 표시 확인
- 전체 Python 검사: 116개 중 114개 통과, 환경 조건 2개 제외
- 추가 보호 검사 포함 복구 관련 검사: 12개 통과
- JavaScript Viewer 검사: 27개 통과
- 새 CFD 계산 실행 없음
