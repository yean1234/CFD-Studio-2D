# CFD Studio 빠른 사용 안내

기존 공통 기능 안내 · 기준일: 2026-09-27

**포대식 쌀 저장고는 최신 [스크린샷 사용법](CFD-STUDIO-USER-GUIDE.md)과 [모델 설명서](CFD-STUDIO-MANUAL.md)를 확인하세요.** 아래는 기존 프로젝트와 실험 묶음의 사용 안내입니다.

CFD Studio는 **설정 선택 → OpenFOAM 계산 → 데이터 보관 → 3D 재생**을 한 프로그램에서 관리합니다. 기존 액침냉각·저장고 프로젝트와 연구용 실험 묶음을 같은 앱에서 엽니다.

## 1. 어떤 화면을 사용하나요?

| 하고 싶은 일 | 화면 | 현재 가능한 작업 |
|---|---|---|
| 기존 액침냉각·저장고 계산 | 메인 화면의 CFD | 프로젝트 생성, 실행·중단·재개 |
| 저장된 결과 확인 | 메인 화면의 Viewer | 결과 변환·업데이트, 3D 재생·내보내기 |
| 작은 추적자 시험 비교 | 상단 `실험 묶음` | 후보 생성, 순차 계산, 품질 검사, 비교·재현 패키지 |
| 저장고 배치·공급 위치 후보 검토 | `/studies/design` | 입력 비교, 형상·제약 검사, 3D 미리보기, 버전 저장 |
| 포대식 저장고 형상 확인 | 설정의 `포대식 저장고 · 형상 사전 검사` | 치수·격자 설정, 형상 사전 검사 |

**연구 변수·3D 후보 화면의 실행 버튼에는 저장고 ClO₂ 계산이 연결되어 있지 않습니다.** 별도 명령줄 연결 솔버와 저장고 결과 화면은 최신 안내에 설명되어 있습니다. 형상 미리보기는 계산 결과가 아닙니다. 추적자 시험의 `C/C_ref`도 실제 ClO₂ 농도나 방제 효과를 뜻하지 않습니다. 기존 저장고 유동 해석이 있다고 해서 새 포대식 저장고의 온도·기류·가스 연성 해석까지 완성된 것은 아닙니다.

## 2. 처음 실행하기

1. 저장소 전체를 내려받고 폴더 배치를 유지합니다.
2. Windows 10/11 x64에 WSL2 Ubuntu를 준비합니다.
3. `cfd_studio/설치.bat`으로 OpenFOAM 계산 환경을 설치합니다. 기존 계산 폴더가 있으면 보호를 위해 중단합니다. 그 폴더를 삭제하지 마세요.
4. `cfd_studio/실행.bat`을 엽니다. 브라우저가 열리지 않으면 실행 창에 표시된 주소로 접속합니다. 기본 주소는 `http://127.0.0.1:8712`입니다.
5. 오른쪽 위 환경 설정에서 CPU·MPI·Raw 저장 위치를 확인합니다. 기본 계산 모드는 CPU Only입니다.

Windows용 Python은 포함되어 있습니다. GPU 모드는 별도 설치·검증이 필요한 개발 기능입니다. 설치 상세는 [앱 사용법](../cfd_studio/README.md)을 참고하세요.

## 3. 프로젝트 계산하기

**새 프로젝트 → 설정 선택 → 출력 선택 → 실행 → 로그 확인**

1. 새 프로젝트를 만들고 액침냉각 또는 기존 저장고 설정을 선택합니다.
2. 설정 옆 `＋`로 선택한 설정의 복사본을 만들 수 있습니다. 기존 프로젝트의 실행 조건은 변경되지 않습니다.
3. 형상·물성·경계조건, 격자, 계산 간격, 종료 조건, 저장 간격을 확인합니다.
4. 필요한 출력을 선택하고 `실행`을 누릅니다. 처음에는 격자 생성·분할이 진행됩니다.
5. 중단 후에는 `실행 재개`를 사용합니다. 재개 시점은 마지막 로그가 아니라 유효한 전체 저장 상태를 기준으로 합니다.

설정 이름이 겹치면 기존 파일을 덮어쓰지 않으므로 새 이름을 입력하세요. 설정창 안에서 유형을 전환할 때는 입력값을 유지하지만, 창을 닫거나 새로고침하기 전에는 저장해야 합니다. 액침냉각에서는 재개용 `전체 상태 저장 간격`과 시각화용 `데이터 추출 간격`을 각각 지정합니다.

계산 중 설정 변경은 차단됩니다. `리셋`은 재개가 아니라 초기화 작업입니다. 브라우저를 닫아도 솔버가 계속 실행될 수 있습니다.

## 4. 결과를 3D로 보기

**Viewer에서 프로젝트 선택 → 처음은 생성 / 새 데이터는 업데이트 → 재생**

이미 변환한 결과는 다시 생성하지 않고 재생합니다. `업데이트`는 새 시점과 미완료 항목을 처리합니다. 아직 저장되지 않은 시점은 변환으로 만들 수 없습니다.

| 결과 종류 | 표시 항목 | 해석할 때 주의할 점 |
|---|---|---|
| 액침냉각 | 기포, 상분율, 속도, 온도 | 속도 표시는 물질 입자의 상변화 이력이 아님 |
| 기존 저장고 | 압력, 난류, 속도 | 정상해석 반복을 실제 경과 시간으로 해석하지 않음 |
| 정규화 추적자 | 농도 C/C_ref, 흡착량 Q/C_ref | 실제 가스 물성·농도 단위와 구분 |

배속을 선택해 재생하고, 끝 지점에서는 재시작 버튼으로 처음부터 볼 수 있습니다. 스크린샷은 UI 없이 프로젝트의 스크린샷 폴더에 저장됩니다. 제공되는 영상·CSV 내보내기도 사용할 수 있습니다.

## 5. 연구용 실험 묶음 사용하기

**실험 생성 → 후보 확인 → 버전 확정 → 실행 예약 → 품질 확인 → 비교·3D 보기**

현재 실제 실행되는 예제는 `porousTracerFoam`의 정규화 추적자 수치 시험입니다. 기본 설치와 별도로 솔버를 빌드해야 합니다. [추가 설치·실험 사용법](research-studies.md)에 절차가 있습니다.

입력 초안은 실험별로 보관합니다. 수정 중에는 이전 확정값으로 실행할 수 없습니다. 서버에 저장한 입력으로 돌아가려면 `저장된 설정 불러오기`를 누릅니다. 결과와 실패 로그는 실행 시도별로 구분합니다.

형상 후보 화면에서는 설계변수·환경/물성·수치 설정을 입력하고 저장량, 충돌, 통로, 공급 위치의 유효성을 검사합니다. 지원되는 탐색·자동 계산 범위는 항목마다 다릅니다. 물성·범위는 임의로 채워지지 않으며, 후보를 확정해도 실제 저장고 가스 CFD가 실행되지는 않습니다.

## 6. 문제가 생기면

| 증상 | 먼저 할 일 |
|---|---|
| 화면과 설정이 달라 보임 | 선택한 프로젝트·실험과 저장된 버전을 확인 |
| 시각화가 중간까지만 있음 | Raw 저장 시점, 변환 로그, 외부 드라이브 연결 확인 |
| 계산 실패 | 첫 오류 주변 로그 확인. 기존 결과를 삭제하지 않기 |
| 실험 대기열이 멈춤 | 환경 오류 또는 중단된 실행 확인. 실제 솔버 정지 확인 후 복구 절차 사용 |
| 디스크 공간 부족 | 계산·변환을 멈추고 프로젝트별 Raw 위치 확인 |

중단 복구 확인만으로 작업이 자동 시작되지는 않습니다. 필요한 작업을 예약한 뒤 `대기열 계속`을 누릅니다. 기존 프로젝트 계산과 실험 묶음 사이의 PC 전체 자원 배분은 아직 통합되어 있지 않습니다.

## 7. 데이터 보관과 공유

- 기존 프로젝트: `cfd_studio/Project/`에 설정·메타데이터·시각화 자료를 보관합니다. Raw는 선택한 드라이브 및 WSL 계산 위치를 별도로 확인하세요.
- 실험 묶음: `cfd_studio/Studies/`에 입력 버전·실행 시도·결과·패키지를 보관합니다.
- Git 공유: 개인 환경, Raw, 실행 로그, 결과·영상은 제외합니다. 사용자 설정 JSON은 자동 비공개가 아니므로 공유 전 내용을 검토하세요.
- 서버는 로컬 PC용입니다. 인터넷에 직접 공개하지 마세요.
