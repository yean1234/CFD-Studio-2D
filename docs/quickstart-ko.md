# 빠른 시작

- CFD Studio V1.0
- 지원 환경: Windows 10/11 x64 · macOS 미지원

## 설치

- WSL2 Ubuntu 설치·사용자 초기화 → `cfd_studio/설치.bat` 실행
- `cfd_studio/실행.bat` 실행 → 브라우저에서 Studio 열기
- 필요한 프로그램과 설치 범위: [설치](../cfd_studio/README.md)

## CFD

| 순서 | 버튼 위치·이름 | 작업 |
|---|---|---|
| 1 | 상단 **CFD** | 프로젝트·계산 화면 열기 |
| 2 | 왼쪽 위 **새 프로젝트** | 이름·프로젝트 폴더·설명·CFD Template 지정 |
| 3 | 생성창 **Config 입력** | Template의 초기 형상과 필수값 확인·입력 · 프리셋 선택 시 해당 값에서 시작 |
| 4 | 프로젝트 화면 **+ CFD Case** | 이름·개별 Config·종료 조건 작성 후 **실행 저장** |
| 5 | 선택한 Case의 **대기열에 추가** | 실행 순서에 등록 |
| 6 | **대기열 시작** | 대기열 전체 순서 확인 후 실행 |
| 7 | 결과 버튼 **생성 / 업데이트 / 열기** | 저장된 결과 준비 또는 Viewer 열기 |

- 기존 프로젝트 연결: 왼쪽 위 **프로젝트 찾기** → 폴더 선택 → 검사 → **추가**
- 새 Template: 왼쪽 **CFD Template 리스트** 오른쪽 **+** → 설문 → 솔버 추천·선택 → 양식·초기 형상 정의 → 저장
- 솔버 설치와 실행 연결은 별도 · 실행 연결이 없는 Template은 Config 작성·보관까지만 지원
- Config 입력: 왼쪽 목록 선택 → 가운데 3D 확인 → 주요 분류의 **JSON**으로 오른쪽 원문 편집
- JSON 저장은 현재 초안 반영 · Config·프로젝트·Case 저장으로 최종 확정
- **프리셋에 저장** 기본 해제 · 체크하면 새 이름으로 별도 저장
- 실행 시작 시 Config 스냅샷 고정 · 새 조건은 **이 Config로 새 Case** 사용
- 실패한 Case는 원인 확인 후 **다시하기** · 중단된 Case는 유효한 재개 데이터가 있을 때 **이어하기**

## Viewer

| 위치·버튼 | 작업 |
|---|---|
| 상단 **Viewer** | 결과 화면 열기 |
| 왼쪽 프로젝트·**CFD Case** 목록 | 조회할 Case 하나 선택 |
| Case 제목 오른쪽 원형 화살표 | 데이터 시각화율 확인 및 업데이트 |
| 왼쪽 **3D Virtual** | 3D 결과·저장 프레임 재생 |
| 왼쪽 **Data Sheet** | 시계열·선상 프로파일 조회 |
| 3D 재생 바 오른쪽 **Export** | 영상·사진 내보내기 |
| Data Sheet **Export** | 그래프 이미지·CSV 내보내기 |

- Case 게이지 100%: 시각화 준비 완료 · 계산 또는 물리 검증 완료를 의미하지 않음
- 3D: 물리량 선택 → 재생 바 탐색 · 드래그 회전·휠 확대/축소
- Data Sheet 왼쪽: **전체 평균 / 특정 좌표** 선택 → 그래프 형식 → 물리량 최대 3개 선택
- Data Sheet 오른쪽: 물리량·저장 프레임·시작점·끝점·표본 수 선택 → **조회**
- 선상 프로파일은 가장 가까운 저장 셀의 값 사용 · 요청 좌표와 실제 셀 좌표를 구분
- 그래프 클릭·드래그로 X·Y 확인 · 미저장 시점이나 물리량은 새로 생성되지 않음
- 전체 Case CSV: **CFD**에서 Case 선택 → **전체 CSV**

## 보관

- 프로젝트 폴더에 Config·Case 기록·원본·시각화·캐시 보관
- 기존 결과의 외부 경로 참조는 유지 · 폴더 이동 전 연결된 원본 확인
- 실행 중에는 프로젝트 위치 변경 불가
- 개인 프로젝트·Raw·결과·프리셋은 소프트웨어 Git 배포에 포함하지 않음
