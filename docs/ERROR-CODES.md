# 오류 코드

- Config 입력·JSON 가져오기·프로젝트 요청의 공통 진단 코드
- 표시: 코드 · 원인 · 항목 경로 · 해결 방법 · 원본 상세
- 코드별 한국어·영어·일본어: [오류 사전](config-error-codes.json)
- 에이전트 조회: `CFDAgent.status().errors`, `CFDAgent.errorInfo("CFG-J004")`
- `retry: review`: 현재 저장 상태와 원인을 확인한 뒤 재시도 · 자동 반복 금지
- 솔버 로그의 모든 오류를 자동 진단하는 체계는 아님 · 분류되지 않은 오류는 APP-X001과 원본 상세 보존

## 에이전트 명령 오류

- 기존 명령 응답의 PAUSED·BUSY·STALE_TARGET·NOT_EDITABLE 등은 조작 상태 코드
- [에이전트 사용법](CFD-STUDIO-AGENT-GUIDE.md)의 명령 오류 표 참고
- 조작 명령 전달 성공과 Config 검사·저장·계산 성공은 별도 확인
