# 설명서 — 무엇을 계산하고 어떻게 읽나요?

화면 조작은 [스크린샷 사용법](CFD-STUDIO-USER-GUIDE.md)을 보세요.
이 문서는 **현재 저장고 모델과 결과의 의미**만 설명합니다.

## 계산하는 대상

| 항목 | 현재 정의 |
|---|---|
| 저장고 | 도면 기준 78 m × 25 m 공칭 외형, 박공지붕 |
| 곡물 | 12개 포대 적재 블록을 균질 다공성 영역으로 정의 |
| 유속 | 온도 차이에 의한 부력과 곡물의 유동 저항을 반영 |
| 온도 | 공기·곡물의 열저장과 열전달을 계산. 외기온은 문헌 도표에서 읽은 시간변화 입력 |
| 농도 | 계산된 흐름에 따른 ClO₂ 이동과 확산 |
| 누출 | 사용자 요청으로 제외. 외부 가스 경계는 밀폐 |

**다공성**은 곡물 사이에 빈 공간이 있고 그 사이로 공기가 이동하는 모델입니다. 포대 하나하나의 천이나 작은 틈을 직접 그린 것은 아닙니다. 공극률 0.4, 투과도 등 곡물·외피 계수는 **미보정 가정값**입니다. 초기 농도도 계산용 가정 분포입니다.

도면의 공칭 외형을 해석 경계로 사용했습니다. 벽 두께를 반영한 실내 순치수는 확정하지 않았으며, 적재 배치는 도면 조건으로 만든 가정 배치입니다. **5 m 부속실 내부 공기, 개별 포대 막 전달, 반응·흡착은 연결 계산에 포함하지 않았습니다.**

## 세 물리량 읽기

| 물리량 | 화면 단위 | 의미 |
|---|---|---|
| 농도 | mg/m³ | 공극 가스의 체적당 ClO₂ 질량. 원본은 kg/m³ |
| 온도 | °C | 열방정식으로 계산한 셀 온도. 원본은 K |
| 유속 | m/s | 겉보기 유속. 화살표는 방향, 길이는 현재 최대 속도에 대한 상대 크기 |

![농도 표시 예시](assets/warehouse-guide/concentration.png)

*농도: 300초 중앙 통로 단면. 파랑은 현재 표시 범위의 낮은 값, 빨강은 높은 값입니다.*

![온도 표시 예시](assets/warehouse-guide/temperature.png)

*온도: 같은 사례·같은 시점의 단면. 외기온을 그대로 칠한 그림이 아니라 계산된 공간 온도장입니다.*

**색만으로 서로 다른 시점을 비교하지 마세요.** 색 범위가 프레임마다 바뀌므로 범례의 숫자와 조회값을 함께 봅니다. 3D 점은 전체 셀의 표본이며, 셀 부피를 채운 그림이 아닙니다.

최신 다공성 사례는 OpenFOAM과 대조한 **셀 체적 중심**을 사용합니다. 위치 조회는 가장 가까운 셀을 선택하고, 저장 시점 사이에서는 시간을 선형 보간합니다. 과거 사례의 근사 대표점과 구분해 화면에 표시합니다.

## ‘완료’와 ‘검증’은 어떻게 다른가요?

| 표시 | 뜻 | 현재 다공성 사례 |
|---|---|---|
| 계산 완료 | 정한 시간까지 실행·출력 검사를 마침 | 300초까지 완료 |
| 보존·원본 검사 | 질량·열수지와 저장값의 일관성 확인 | 통과 |
| 격자 수렴 | 칸을 더 잘게 나눠도 결과가 충분히 비슷함 | 기준 미달 |
| 시간간격 검사 | 계산 간격을 줄여도 결과가 충분히 비슷함 | 기준 미달 |
| 실험 검증 | 독립 실측과 비교해 정확도 확인 | 미완료 |

세 격자 중 중간·세분 격자의 마지막 시점 차이는 **농도 약 33%, 유속 약 35%**였습니다. 시간간격을 절반으로 줄인 비교에서도 일부 시점의 농도 차이가 **9.2%**로 5% 목표를 넘었습니다. 따라서 현재는 **가정 시나리오를 실행·조회할 수 있는 모델**이며, 수렴한 정량 예측으로 판정하지 않습니다.

외기온이 시간에 따라 변하므로 계산 종료를 정상상태 도달로 해석하지 않습니다.
