## 프로젝트와 실행

- CFD FORM: 해석 대상·솔버·입력 파트·기본 Config 정의
- 프리셋: 각 FORM에 속한 값 묶음
- 프로젝트: 이름·설명·CFD FORM·기본 프리셋 참조·실행 목록 보관
- 기본 프리셋 변경: 이후 생성하는 실행에만 적용
- +CFD Case: 개별 설정·목표·종료 조건을 초안으로 저장
- 실행 시작: 입력 JSON과 SHA-256 고정, 다른 실행·프리셋에 소급 적용하지 않음
- 대기열: 순서·제외·다음 실행부터 일시정지, 실패 시 자동 정지
- 재시도: 별도 시도 폴더, 완료 계산 자동 재실행 차단
- 수렴 종료: 연속 유지 구간 판정 미연결로 선택 비활성
- 프레임 종료: 초기 프레임 포함 여부와 완전 저장 개수 확인
- Config 보기: 계산 중·완료 후 실행에 사용한 입력 조회, 기존 입력 수정 차단
- 저장 설정: 프로젝트와 독립, `cfd_studio/_runtime/executions/presets`에 보관
- 설정 가져오기·내보내기: JSON 파일 사용
- 출처·근거: 설정 목록 마지막 **출처** 항목에 표시, 원본 입력 유지
- 공통 Viewer: 이중액침·저장고·정규화 결과에서 동일한 캔버스·재생·레이어·Export 사용
- 저장고 전용 화면 제거, 모델별 데이터 연결만 구분
- 실행 전환 상태: 현재 탭에서 실행별 시간·물리량·시점 유지
- 실행별 보관: 입력 사본·입력 SHA-256·솔버 로그·계산 원본·조회용 배열
- 재실행: 새 실행과 새 결과 폴더 생성, 앞선 결과 보존
- 실행 완료: 지정 시간까지 계산·출력 검사 통과
- 수치 수렴·실험 검증: 실행 완료와 별도 표시
- 저장고 기록: 식량창고 프로젝트의 실행 목록으로 통합
- 이중액침 기록: 별도 프로젝트 유지, 외부 원본 폴더 참조
- 외부 연결 목록: `cfd_studio/_runtime/executions/external_results.json`
- 저장 위치: 프로젝트 생성·설정에서 지정한 폴더
- 백업: 프로젝트 폴더 전체와 이전 형식의 외부 연결 원본 보존
- 계산 환경: WSL OpenFOAM·Linux NumPy 필요
- 앱 재시작: 실행 기록·대기열 복원, 다음 실행은 일시정지
- 실행 중 계산: 완료 기록을 추적, 시작한 시도 자동 재실행 차단
- 기록 파일: `queue.json`, 시도별 `input.json`, `job.json`, 로그
- 액침냉각: 적용된 입력을 `applied_input.json`에도 보관

## 저장 구조

| 위치 | 내용 |
|---|---|
| `project.cfdproj` | 프로젝트 이름·설명·기본 프리셋 참조·실행 연결 |
| `ProjectSettings/executions.json` | Case 설정·목표·종료 조건·대기열 기록 |
| `Cases/<Case>/Attempts/<시도>/input.json` | 실행 시 고정된 설정 스냅샷 |
| 같은 시도 폴더의 `job.json`, 로그 | 실행 상태·입력 해시·로그 |
| 같은 시도 폴더의 `Raw` | 저장고 계산 원본·조회 배열 |
| 같은 시도 폴더의 `Results/<실행>` | 이중액침 등의 Viewer 결과·설정·Raw_Data·변환 캐시 |
| `Results` | 기존 결과를 프로젝트로 복사할 때의 보관 위치 |
| `Cache` | 프로젝트 캐시 영역 |

- Studio 공통 목록: 프로젝트 경로와 전체 대기열 순서 참조
- 설정 프리셋: Studio에서 독립 관리. 실행 입력은 프로젝트 안에 별도 보관
- Windows 드라이브: 지정 경로 유지. WSL 실행 시 드라이브 경로 변환
- 이중액침 계산 작업 공간: WSL 공통 작업 폴더 사용. 완료 시 프로젝트에 원본 복사·검증 후 다음 Case 진행
- 저장고: 프로젝트 내부의 독립 실행 폴더에서 계산
- 기존 형식: 원본 이동 없이 연결 유지. 위치 변경 시 복사 후 파일 해시 검사
- 경로 변경 실패: 기존 프로젝트 연결 유지, 부분 복사본은 새 위치에 남을 수 있음
- Studio 재시작: 등록된 프로젝트 실행 기록과 대기열 복원
- 소프트웨어 설정의 전역 Raw 위치 지정 기능 제거. 과거 경로 값은 이전 결과 조회에만 사용

## 계산 대상

| 항목 | 현재 정의 |
|---|---|
| 저장고 | 도면 기준 78 m × 25 m 공칭 외형, 박공지붕 |
| 곡물 | 12개 포대 적재 블록을 균질 다공성 영역으로 정의 |
| 유속 | 온도 차이에 의한 부력, 곡물의 유동 저항 반영 |
| 온도 | 공기·곡물의 열저장·열전달 계산, 문헌 도표의 외기온 시간변화 입력 |
| 농도 | 계산된 흐름에 따른 ClO₂ 이동·확산 |
| 누출 | 사용자 요청으로 제외, 외부 가스 경계 밀폐 |

- 다공성: 곡물 사이 빈 공간을 통한 공기 이동 모델
- 포대 표현: 적재 블록의 등가 영역 사용, 개별 천·작은 틈 미해상
- 공극률 0.4·투과도·곡물 및 외피 계수: **미보정 가정값**
- 초기 농도: 계산용 가정 분포
- 해석 경계: 도면 공칭 외형 사용
- 실내 순치수: 벽 두께 미반영, 미확정
- 적재 배치: 도면 조건에 따른 가정 배치
- 미포함 항목: **5 m 부속실 내부 공기, 개별 포대 막 전달, 반응·흡착**

## Viewer 모드

- **3D Virtual Viewer**: 활성 Case 하나의 3D 결과·재생
- **Data Sheet Viewer**: 프로젝트에서 선택한 Case의 그래프 조회
- Case 이름 버튼: 활성 3D 결과 변경
- Case 이름: 3D와 그래프에 적용할 실행 하나 선택
- CFD Case 제목 오른쪽 **다시 읽기**: 선택한 실행 결과 갱신
- 그래프: 읽은 구간의 저장값 표시, 클릭 위치에서 가장 가까운 저장 X 선택
- 값 표시: 저장 정밀도 유지, 같은 X가 없는 Case는 빈값, 보간하지 않음
- 선 연결: 저장점 사이의 시각적 연결, 중간값을 새 계산값으로 제공하지 않음
- 단위 또는 시간축 종류가 다른 Case는 같은 곡선 비교에서 제외
- 비정상 해석 X축: 물리시간 s
- `simpleFoam` 정상 해석 X축: 솔버 반복 횟수
- 큰 결과: 16개부터 읽고 사용자 요청으로 전체 구간 조회, 읽은 개수 표시
- 재생·하단 표·모델 검증 탭 제거, Config와 원본 검증 기록 보존
- 위치·시간 조회: 저장고 Case를 선택한 경우 아래 접기 영역
- 원본 폴더: **CFD → 결과 폴더**

### 그래프 항목

| 해석 | 저장된 출력 |
|---|---|
| 이중액침 | 온도·층별 온도·유속·속도 성분·상분율·열전대·코일·기포 |
| 저장고 | 농도·온도·유속·속도 성분 |
| 단상 저장고 | 유속·속도 성분·압력·난류 운동에너지·소산율 |
| 정규화 추적자 | 농도·흡착량 |

- 격자장: 평균·최솟값·최댓값 선택
- 저장고: 원본장과 배열을 대조한 전체 저장 셀의 산술 통계
- 기존 이중액침·단상 결과: 저장 시각화 격자의 통계, 체적 가중 평균 아님
- 기존 온도 빈 셀 제외, 상분율 점유 마스크 적용, 구형 유속·압력·난류의 빈 평면 처리는 3D와 동일
- 압력: Case에 밀도가 저장된 경우 Pa, 그렇지 않으면 원래 단위 m²/s²
- T5: Case에 저장된 입구 온도 입력값
- T6: Case의 코일 이력·유량·전열계수에서 기존 식으로 계산한 값, 직접 측정값 아님
- 열전대: 저장된 이력 전체 조회 가능, 최근 600개 제한 제거
- 없는 필드는 그래프 메뉴에 생성하지 않음
- 사용자 정의 FORM: 지원 엔진의 출력 목록을 따름, 새로운 솔버의 임의 출력 형식은 별도 연결 필요
- 수치 검증·실험 검증 완료 여부는 그래프 표시 성공과 별개

### Config 검색

- 항목명·분류명·설정 키로 검색
- 예: `발열`, `냉각 코일 온도`, `결과 프레임 저장 간격`
- 종료 조건과 출력 항목도 검색 가능
- 검색어를 지우면 선택했던 분류로 복귀
- 검색 중 편집한 값은 유지. 저장된 실행 설정은 조회만 가능

### 폴더

- `Projects`: 기본 위치에 만든 프로젝트. 설정·Case·결과를 프로젝트별 보관
- `configs`: 독립 설정 프리셋
- `Setup`: 실행에 필요한 Python과 설치 파일
- `Studies`: 이전 실험 묶음의 설정·실행 이력

- 기존 `Project` 결과를 옮길 때는 프로젝트 연결도 함께 갱신
- Raw 폴더에 이전 경로를 가리키는 링크가 있으면 링크도 확인

### Config 차이

- Case 생성 시 저장한 기준 설정과 해당 Case의 설정 비교
- 기본 프리셋으로 만든 Case는 생성 당시 프리셋이 기준
- 프로젝트 기본 프리셋을 나중에 바꿔도 기존 Case의 기준은 유지
- 비교 기준이 없는 이전 결과는 `기준 없음` 표시
- 펼친 본문은 최소 높이와 여백 유지, 긴 목록은 내부 스크롤

## CFD FORM

- 기본 FORM: 이중액침냉각 / 옥수수 사일로 / 식량 저장고 훈증 시스템
- 새 FORM: 범용 OpenFOAM 솔버 10개와 기존 전용 구성 2개 선택. [솔버 목록·지원 범위](solver-catalog-20260929.md)
- 실행 연결: 이중액침 `icoReactingMultiphaseInterFoam`, 옥수수 사일로 `simpleFoam`·`pimpleFoam`, 저장고 `warehouseBuoyantFoam`
- 미연결 솔버: 입력 계획을 FORM 초안으로 저장. 프로젝트·Case 실행에는 적용 불가
- 설치 확인: CPU OpenFOAM 실행 파일 존재 여부만 확인. Studio 연결·버전 호환·계산 성공과 구분
- FORM 생성 후 해석 대상·솔버 고정. 이름·파트 제목·기본 Config 수정 가능
- 신규 프로젝트: FORM 필수, 다른 FORM의 프리셋 차단
- 기존 프로젝트: 저장된 프리셋·결과 유형으로 FORM 연결, 원본 Config·결과 보존
- Case: Config·비교 기준·FORM 버전을 개별 보관
- FORM·기본 프리셋 수정: 이미 저장된 Case에 소급 적용하지 않음
- FORM 등록부: `cfd_studio/_runtime/executions/forms.json`
- FORM별 신규 프리셋: `cfd_studio/_runtime/executions/form_presets`
- 이전 프리셋: 원본 파일 유지, 해석 유형별 기본 FORM에 연결
- 백업: 프로젝트 폴더와 위 FORM·프리셋 등록부 보관

## 카메라

- 이중액침·저장고·사일로·추적자: 같은 드래그 방향으로 회전
- 모델의 위쪽 축 차이: 회전 입력에서 보정
- 휠: 모델 크기에 비례한 확대·축소, 한 번의 입력 변화량 제한 유지


## 저장고 표시 밀도

- 기본 표시 밀도: 세밀
- 벡터 상한: 표준 1,500개, 세밀 6,000개, 매우 세밀 18,000개
- 위치 선택: 공간 구역별 실제 저장 셀 중심, 원본 인덱스 간격에 따른 줄 생략 제거
- 단면: 단면에 해당하는 셀을 먼저 고른 후 밀도 적용
- 최대 유속의 2.5% 미만을 일괄 숨기던 조건 제거, 정지 벡터는 생략
- 화살표 길이: 셀 간격과 상대 유속에 맞춘 표시 길이, 입자의 실제 이동 거리 아님
- 읽기 상한: 프레임당 125,000셀, 상단에서 표시 / 전체 셀 확인
- 큰 결과의 메모리 사용: 프레임 크기에 따라 최근 2~8프레임 유지
- 저장된 계산값·계산 격자 변경 없음, 공간 사이의 새 CFD 값 생성 없음
- 표시 밀도 증가와 계산 격자 세분화는 별개

## 사용자 정의 Config

- 새 FORM: 솔버 선택 후 질문 응답으로 형상·물성·초기장·경계조건·수치·종료·출력 양식 생성
- 항목: Key·Type·Unit·Value, 중첩 Object·Array 지원
- 필드 이름: 사용자 입력 그대로 보존. 한글 이름 자동 변환 없음
- Type·Unit: FORM 스키마로 저장. Unit은 자동 단위 변환 기능이 아닌 메타데이터
- JSON 가져오기·내보내기: Config 값만 포함. Type·Unit 스키마는 FORM 저장에 포함
- 기존 연결 템플릿: 필수 입력·솔버 계약 유지
- 사용자 정의 FORM: 입력·결과 어댑터 연결 전까지 정의만 저장. 솔버 설치만으로 임의 Config 계산 불가
- [Config 편집](generic-config-20260929.md)
