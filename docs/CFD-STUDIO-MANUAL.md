## 프로젝트와 실행

- 프로젝트: 이름·설명·기본 프리셋 참조·실행 목록 보관
- 기본 프리셋 변경: 이후 생성하는 실행에만 적용
- +CFD Case: 개별 설정·목표·종료 조건을 초안으로 저장
- 실행 시작: 입력 JSON과 SHA-256 고정, 다른 실행·프리셋에 소급 적용하지 않음
- 대기열: 순서·제외·다음 실행부터 일시정지, 실패 시 자동 정지
- 재시도: 별도 시도 폴더, 완료 계산 자동 재실행 차단
- 수렴 종료: 연속 유지 구간 판정 미연결로 선택 비활성
- 프레임 종료: 초기 프레임 포함 여부와 완전 저장 개수 확인
- 설정 보기: 계산 중·완료 후 실행에 사용한 입력 조회, 기존 입력 수정 차단
- 저장 설정: 프로젝트와 독립, `cfd_studio/_runtime/executions/presets`에 보관
- 설정 가져오기·내보내기: JSON 파일 사용
- 출처·근거: 설정 목록 마지막 **출처** 항목에 표시, 원본 입력 유지
- 공통 Viewer: 이중액침·저장고·정규화 결과에서 동일한 캔버스·재생·레이어·Export 사용
- 저장고 전용 화면 제거, 모델별 데이터 연결만 구분
- 실행 전환 상태: 현재 탭에서 실행별 시간·물리량·시점 유지
- 실행별 보관: 입력 사본·입력 SHA-256·솔버 로그·계산 원본·조회용 배열
- 재실행: 새 실행과 새 결과 폴더 생성, 앞선 결과 보존
- 실행 완료: 지정 시간까지 계산·출력 검사 통과
- 수치 수렴·실험 검증: 실행 완료와 별도 표시
- 저장고 기록: 식량창고 프로젝트의 실행 목록으로 통합
- 이중액침 기록: 별도 프로젝트 유지, 외부 원본 폴더 참조
- 외부 연결 목록: `cfd_studio/_runtime/executions/external_results.json`
- 저장 위치: 프로젝트 생성·설정에서 지정한 폴더
- 백업: 프로젝트 폴더 전체와 이전 형식의 외부 연결 원본 보존
- 계산 환경: WSL OpenFOAM·Linux NumPy 필요
- 앱 재시작: 실행 기록·대기열 복원, 다음 실행은 일시정지
- 실행 중 계산: 완료 기록을 추적, 시작한 시도 자동 재실행 차단
- 기록 파일: `queue.json`, 시도별 `input.json`, `job.json`, 로그
- 액침냉각: 적용된 입력을 `applied_input.json`에도 보관

## 저장 구조

| 위치 | 내용 |
|---|---|
| `project.cfdproj` | 프로젝트 이름·설명·기본 프리셋 참조·실행 연결 |
| `ProjectSettings/executions.json` | Case 설정·목표·종료 조건·대기열 기록 |
| `Cases/<Case>/Attempts/<시도>/input.json` | 실행 시 고정된 설정 스냅샷 |
| 같은 시도 폴더의 `job.json`, 로그 | 실행 상태·입력 해시·로그 |
| 같은 시도 폴더의 `Raw` | 저장고 계산 원본·조회 배열 |
| 같은 시도 폴더의 `Results/<실행>` | 이중액침 등의 Viewer 결과·설정·Raw_Data·변환 캐시 |
| `Results` | 기존 결과를 프로젝트로 복사할 때의 보관 위치 |
| `Cache` | 프로젝트 캐시 영역 |

- Studio 공통 목록: 프로젝트 경로와 전체 대기열 순서 참조
- 설정 프리셋: Studio에서 독립 관리. 실행 입력은 프로젝트 안에 별도 보관
- Windows 드라이브: 지정 경로 유지. WSL 실행 시 드라이브 경로 변환
- 이중액침 계산 작업 공간: WSL 공통 작업 폴더 사용. 완료 시 프로젝트에 원본 복사·검증 후 다음 Case 진행
- 저장고: 프로젝트 내부의 독립 실행 폴더에서 계산
- 기존 형식: 원본 이동 없이 연결 유지. 위치 변경 시 복사 후 파일 해시 검사
- 경로 변경 실패: 기존 프로젝트 연결 유지, 부분 복사본은 새 위치에 남을 수 있음
- 폴더 열기: 프로젝트 실행 기록과 대기열 복원, 자동 실행 방지
- 소프트웨어 설정의 전역 Raw 위치 지정 기능 제거. 과거 경로 값은 이전 결과 조회에만 사용

## 계산 대상

| 항목 | 현재 정의 |
|---|---|
| 저장고 | 도면 기준 78 m × 25 m 공칭 외형, 박공지붕 |
| 곡물 | 12개 포대 적재 블록을 균질 다공성 영역으로 정의 |
| 유속 | 온도 차이에 의한 부력, 곡물의 유동 저항 반영 |
| 온도 | 공기·곡물의 열저장·열전달 계산, 문헌 도표의 외기온 시간변화 입력 |
| 농도 | 계산된 흐름에 따른 ClO₂ 이동·확산 |
| 누출 | 사용자 요청으로 제외, 외부 가스 경계 밀폐 |

- 다공성: 곡물 사이 빈 공간을 통한 공기 이동 모델
- 포대 표현: 적재 블록의 등가 영역 사용, 개별 천·작은 틈 미해상
- 공극률 0.4·투과도·곡물 및 외피 계수: **미보정 가정값**
- 초기 농도: 계산용 가정 분포
- 해석 경계: 도면 공칭 외형 사용
- 실내 순치수: 벽 두께 미반영, 미확정
- 적재 배치: 도면 조건에 따른 가정 배치
- 미포함 항목: **5 m 부속실 내부 공기, 개별 포대 막 전달, 반응·흡착**

## 표시와 조회

- 저장고 색 범위: 보간하는 두 저장 프레임의 최솟값·최댓값, 범례 숫자 확인
- 저장고 애니메이션: 같은 셀 표본의 농도·온도·유속을 시간에 따라 선형 보간
- 화면 보간: 시각화 기능, 원본장·수치 해상도·물리 검증 상태는 그대로 유지
- 흐름 마커: 유속 방향 표시용 이동 표식
- 그래프: 읽어온 저장 프레임의 원본장 범위
- 재생 배속: 물리시간 기준
- 농도·온도 표현: 셀 표본에 부드러운 점을 겹친 체적 표현
- 표면·포대 형상: 저장고 외곽과 등가 다공성 블록
- 화살표 길이: 현재 최대 속도에 대한 상대 크기
- 최신 다공성 사례: OpenFOAM과 대조한 **셀 체적 중심** 사용
- 위치 조회: 가장 가까운 셀 선택
- 시간 조회: 저장 시점 사이 선형 보간
- 과거 사례: 근사 대표점 사용 여부를 화면에 별도 표시

## Viewer 모드

- 기본 모드: **3D Virtual Viewer**
- 전환 모드: **Data Sheet Viewer**
- 동일 Case·재생 시점·카메라 유지
- Data Sheet: 물리량 선택·시간 그래프·표·CSV
- 위치·시간 조회, 모델·검증 정보: Data Sheet 아래 접기 영역
- 원본 경로 나열 제거, 폴더 접근은 **CFD → 결과 폴더**
- 프로젝트 저장 경로: **프로젝트 설정**에서 확인·변경
- 저장고 그래프: 표시용 셀 표본의 최솟값·최댓값, 유속은 최댓값
- 정규화 추적자: 읽은 격자 값의 범위
- 이중액침 열전대: 최근 600개 기록, T5 설정값·T6 계산값 구분
- 누락 데이터는 빈칸, 전체 원본장 통계나 실험 검증으로 해석하지 않음

### 설정 검색

- 항목명·분류명·설정 키로 검색
- 예: `발열`, `냉각 코일 온도`, `결과 프레임 저장 간격`
- 종료 조건과 출력 항목도 검색 가능
- 검색어를 지우면 선택했던 분류로 복귀
- 검색 중 편집한 값은 유지. 저장된 실행 설정은 조회만 가능
