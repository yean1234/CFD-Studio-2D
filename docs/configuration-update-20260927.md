# 공통 설정 보완 기록

## 이번에 수정한 범위

기존 액침냉각·단상 저장고의 새 설정창과 공통 저장 API를 보완했다. 기존 프로젝트·Raw·기준 프리셋의 연구값은 수정하지 않았다. 독성 가스의 공급·노출 계산 연결은 이번 변경 대상이 아니다.

| 항목 | 동작 |
|---|---|
| 유형 전환 | 설정창을 열어 둔 동안 유형별 입력 초안을 유지 |
| 솔버 전환 | 정상해석 반복 횟수와 비정상해석 시간·간격을 별도 보관 |
| 복제 원본 | 설정창을 연 시점의 원본을 복사; 뒤늦은 조회 결과와 섞지 않음 |
| 저장 | 입력 잠금, 중복 클릭 차단, 통신 실패 시 편집값 유지 |
| 중복 이름 | HTTP 409, 기존 JSON 보존; 대소문자만 다른 이름도 충돌 처리 |
| 이름·입력 검사 | Windows 예약 파일명, 빈 숫자, 비유한 값, 소수 격자 수 거부 |
| 시간 설정 | 저장 간격과 종료값 검사; 반복 횟수와 물리시간 구분 |
| 재개용 출력 | 액침냉각 전체 상태 저장 간격을 설정창에서 직접 편집 |
| 저장 응답 | 대기 중 선택한 프로젝트·설정이 바뀌어도 새 응답으로 덮어쓰지 않음 |

초안은 설정창 내 전환용이며 브라우저 새로고침·창 닫기 이후의 영구 저장은 아니다. 미정 물성·연구 조건을 추정하여 채우지 않았다. 기존 예제 프리셋의 값은 원본 그대로 사용하며 이번 변경이 그 값의 실험적 타당성을 검증한 것은 아니다.

## 검사

- Python 통합 검사 72개 통과.
- JavaScript 회귀 검사 22개 통과.
- Windows embedded Python의 새 프리셋 검사 10개 통과.
- 전용 브라우저에서 18항목 확인: 유형·솔버 전환, 실제 JSON 저장·재조회, 중복 저장, 통신 실패, 데스크톱 1440×1000 및 모바일 390×844 레이아웃.
- 예상된 HTTP 409와 의도적으로 끊은 요청을 제외하고 처리되지 않은 브라우저 스크립트 오류는 없었다.

검사 서버는 운영 앱을 시작하지 않으며 실제 솔버 실행 경로도 제공하지 않는다. 임시 폴더의 프리셋만 저장한다. 테스트용 수치 변경은 물성 추천이나 CFD 결과가 아니다. 기존 사용자 Chrome과 진행 중인 계산에는 접근하지 않았다.

```bash
python -m unittest discover -s tests -v
node --test tests/test_viewer_review.js
python tests/serve_config_review.py output/study_config_new_review --port 8751
```

전용 Playwright 세션에서 위 서버를 열고 `tests/browser_config_workflow.js`를 실행한다. 스크린샷은 `output/playwright/config-review-desktop.png`, `config-review-mobile.png`에 저장되며 Git 제외 대상이다.

## 완료로 표시하지 않는 항목

- 선정한 포대식 저장고 형상을 실제 열·유동 해석에 연결하는 새 실행 모델을 이번 작업에서 구현하지 않았다.
- 실제 ClO₂ 물성 입력·반응 모델·공급조건 실행 연결 및 실험 비교는 포함하지 않았다.
- 새 장시간 CFD 계산이나 GPU 성능 검증을 수행하지 않았다.

따라서 이번 변경은 **공통 설정 편집·저장 경로의 보완**이며, 연구용 저장고 해석 전체가 완성됐다는 의미가 아니다.
