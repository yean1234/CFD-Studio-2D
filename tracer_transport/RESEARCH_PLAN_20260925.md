기준 자료: 사용자가 제공한 `상세연구계획서.pdf`, 2026-09-25, 19쪽.
원본 문서와 기존 프로젝트·PH3 추적자 시험 설정은 변경하지 않았다.

## 연구계획 변경점

- 1, 9쪽: 대상은 ClO2. 기존 PH3 연구용 정규화 추적자 시험을 ClO2 검증 결과로 바꾸어 표시하지 않는다.
- 4-5쪽: 저장동 전체 78 x 25 m, 처마 높이 7.20 m, 지붕 상승 3.50 m. 전면 5 m 부속부는 별도 공간이다.
- 5쪽: 벽 두께와 유효 실내 치수는 구분한다. 현재 격자는 도면 공칭 외곽 기준이며 확정 실내 공기 부피가 아니다.
- 6, 9쪽: 열·유동장과 비정상 농도장을 구분하고, 곤충 모델은 외부 후처리로 분리한다.
- 9쪽: 재료 축적과 비가역 반응 소모, 외부 순유출을 분리한 수지가 필요하다. 가역 흡착 시험만으로 반응성 종 수송을 구현했다고 할 수 없다.
- 11쪽: 유동·열조건이 달라지면 기존 장을 재사용할 수 없다. 정상상태 도달과 공통 처리시간의 종료도 구별해야 한다.

## 추가한 실행 가능 구성

`warehouse_geometry.py`는 화학종과 독립적인 형상 사전 검사기다.
길이·폭·처마 높이·지붕 상승·각 방향 셀 수·최대 셀 수를 JSON으로 설정한다.
NaN, 음수, 잘못된 키, 셀 예산 초과를 거부한다. 기존 경로를 덮어쓰지 않는다.
실패 로그와 결과 상태를 보존하며, 격자 성공을 수송 계산 완료로 보고하지 않는다.

```bash
source /usr/lib/openfoam/openfoam2312/etc/bashrc
python3 -m tracer_transport.warehouse_geometry \
  --config tracer_transport/warehouse_geometry_20260925.json \
  --output output/warehouse_geometry_new \
  --check-mesh
```

저장동 끝면의 `annexInterface`는 향후 경계 분할을 위한 이름일 뿐이다.
현재는 밀폐 벽이며, 실제 문·연결 개구부나 부속실 누출을 재현하지 않는다.
셀 수는 형상 시험용 가정이다. 격자 독립성이 확인된 해석 설정으로 제시하지 않는다.

## 본 해석 전 필요한 입력

1. 확정 적재 블록·팔레트 배치와 공통 저장량.
2. 공극률, 유동 저항, 유효 확산 및 재료 전달·소모의 출처와 단위.
3. 초기장과 열·유동·종 수송의 경계조건 표.
4. 물리적 종료 조건, 내부 시간 간격, 출력 간격을 각각 지정.
5. 실제 연결 개구부, 누출 평가 영역 및 독립 검증 자료.

미확정 값을 추적자 시험 수치로 대체하지 않는다. 이 변경은 전체 연구 CFD 시스템의 완성이 아니라 형상 사전 검사 단계다.

## Studio 연결 (v176 개발본)

새 설정 만들기의 해석 유형에서 `포대식 저장고 · 형상 사전 검사`를 선택하면
동일한 Studio 서버의 `/warehouse` 설정 화면으로 이동한다.
치수·격자 편집, 새 설정 저장, OpenFOAM 격자 검사, 검사 이력 표시를 지원한다.
기존 액침냉각·원통형 저장고 설정 및 결과는 변경하지 않는다.

- 설정은 이름이 같아도 고유 ID로 저장하며 기존 설정을 덮어쓰지 않는다.
- 검사 결과·실패 로그·입력 사본은 `cfd_studio/_runtime/warehouse`에 보존한다.
- 프로그램 재시작 시 검사 이력을 읽는다. 중단된 검사는 성공 또는 무한 실행으로 표시하지 않는다.
- 격자 검사는 한 번에 한 건만 실행한다. 실제 가스 솔버는 호출하지 않는다.
- 2026-09-25 실제 Studio HTTP 처리기와 브라우저에서 저장·검사 버튼을 실행하여 22,308셀 검사 통과를 확인했다.
- 개발본 점검 서버는 자동 재개·원본 데이터 이관 작업을 시작하지 않고 HTTP 화면과 격자 검사만 제공한다.
- 현재 Windows/WSL 실행 경로는 구현했지만 실제 버튼 검증은 WSL에서 구동한 서버에서 수행했다.

기존 설치본에 자동 덮어쓰기하지 않았다. 전면 개편과 본 해석 연계는 여전히 미완료다.
