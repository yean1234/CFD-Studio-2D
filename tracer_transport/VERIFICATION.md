- 2,560셀 3D 사례를 1초까지 연속 계산하고, 별도로 0.5초까지 계산한 뒤 재개했습니다. 최종장 최대 절대 차이는 1.9984e-15 C/C_ref로 사전 기준 1e-10을 통과했습니다.

- 일부러 잘못된 선형 솔버명을 넣어 OpenFOAM을 실제 실패시켰습니다. FATAL 오류 로그를 보존했으며 이 사례를 성공 계산으로 집계하지 않았습니다.

## 추가 범용성 점검

x축 슬래브만 지정하던 입력을 3차원 다공성 직육면체 목록으로 확장했습니다. 외곽 크기·블록 경계·횡방향 격자 수는 JSON, x방향 격자와 시간간격은 실행 인자로 받습니다. 잘못된 경계·겹침·격자면 불일치는 명시적으로 거부합니다.

block3d_test.json으로 2,560셀의 자유 공기/다공성 블록 단상 추적자 확산을 실제 실행했습니다. 물리시간 1초, 계산 간격 0.005초, 실행 측정 0.174초, 최대 상대 질량 변화 4.30e-14, 음수 없음, 솔버 최대 RSS 33,688 KiB였습니다. 단위 검사 11개도 통과했습니다.

이것은 사용자가 선정한 저장고 설계의 실행이 아닙니다. 선정 설계 파일/설정명이 확인되지 않았으며, 포대식 자료의 5톤·100포대로 실제 치수를 임의 역산하지 않았습니다. 설정 확정 전까지 해당 결과를 실제 훈증 농도나 설계 검증으로 사용하지 않습니다.

## 실행 범위

WSL2 Linux, OpenCFD v2312 patch 260127, GCC 기반 DP/Int32 빌드의 사용자 솔버 porousTracerFoam을 실제 컴파일·실행했습니다. 기존 Studio의 액침냉각/저장고 케이스와 Chrome은 변경하거나 실행하지 않았습니다. 기존 코드 보존을 위해 실험 모듈만 별도 폴더에 추가했습니다.

개발 지시서, 16쪽 연구 워크플로우 PDF, Arora 자료 조사 목록, 확보된 Agrafioti 본문을 읽었습니다. Arora 2025 전문이나 실측 센서 시계열을 새로 확보했다고 주장하지 않습니다.
