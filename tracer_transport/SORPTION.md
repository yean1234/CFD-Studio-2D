# 가역 흡착·탈착: 정규화 수치검증 단계

## 현재 구현

단일 기체상 농도 C와 정지한 고체에 보유된 양 Q를 따로 계산합니다. Q는 **벌크 체적당 보유량을 C_ref로 나눈 값**이며 공극 농도나 쌀 질량당 흡착량이 아닙니다. 흡착된 양을 두 번째 유동상으로 풀거나 곤충·입자 모델로 나타내지 않습니다.

```
d(eps*C)/dt + div(U_s*C) = div(K*grad(C)) - k_ads*C + k_des*Q
dQ/dt = k_ads*C - k_des*Q
M_total = integral(eps*C + Q) dV
```

eps는 공극률, K는 이미 벌크 면적 기준인 유효 확산계수입니다. k_ads와 k_des는 위 정의에 따른 1/s 계수입니다. 같은 문헌에 1/s 단위가 있더라도 흡착량의 기준 체적·질량이 다르면 그대로 사용할 수 없습니다.

두 식을 같은 backward Euler 단계로 결합하고 Q를 대수적으로 소거하여 C를 계산한 뒤 Q를 갱신합니다. 기체에서 빠진 양과 고체에 들어간 양에 같은 교환항을 사용합니다. 음수 clipping은 사용하지 않습니다. 흡착·탈착은 다공성 영역에만 작용합니다.

이 선형 모델에는 유한 흡착 용량·포화·비선형 등온식이 없습니다. PH3-쌀 물성으로 검증한 모델이 아닙니다. 이번 계수는 해석해와 수지 검사를 위한 **명시적 수치시험 가정**이며 실제 훈증 조건에 적용하지 않습니다.

## 사전 검사 기준

- 기체+흡착 상대 질량 오차 < 1e-8.
- C와 Q 모두 >= -1e-10, clipping 없음.
- 공간 균일 ODE 해석해에 대한 C와 Q의 RMSE 중 큰 값 < 0.002.
- dt=0.02, 0.01, 0.005 s 순서로 해석해 오차 감소.
- 계수 0과 흡착 기능 비활성의 최종 C 최대 차이 <= 1e-12.
- 연속 계산과 중단·재개의 C 및 Q 최대 차이 <= 1e-10.
- C와 Q 중 하나라도 없는 저장 시각은 건너뛰고 원본을 보존.

균일 해석해는 lambda=k_ads/eps+k_des,
C_eq=k_des*(eps*C0+Q0)/(k_ads+eps*k_des),
C(t)=C_eq+(C0-C_eq)*exp(-lambda*t), Q(t)=eps*C0+Q0-eps*C(t)입니다.
두 계수가 모두 0이면 초기 상태를 유지합니다.
