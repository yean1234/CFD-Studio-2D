# PH3 대상 수송 연구: 단계별 계약과 검증

## 1. 모델의 구분

최종 대상 화학종은 포스핀(PH3)입니다. 현재 실행기는 **단일 기체상의 정규화 비반응 추적자**만 구현합니다. 다공성 영역은 고체 쌀 내부의 공극을 연속체로 표현하는 구역이지 별도 액체상이나 다상 VOF가 아닙니다. 지금의 C/C_ref를 PH3의 ppm 또는 mg/m3로 바꿔 표시하지 않습니다.

model_kind=PH3, 막 저항, 누설, 알 수 없는 입력 항목은 현재 실행기에서 명시적으로 거부합니다. 공급은 SUPPLY_AND_3D.md의 정규화 유한 펄스 수치시험만, 흡착은 SORPTION.md의 정규화 선형 교환 시험만 지원합니다. 실제 약제 운용이나 살포 처방을 제공하지 않습니다.

## 2. 곤충 모델 분리

CFD 솔버에는 곤충·행동·입자·경로·사망률 모델이 없습니다. sample.py는 저장된 concentration.npz만 읽는 **오프라인 후처리**입니다. solver는 이 파일을 import하거나 호출하지 않습니다. 인공 경로 적분은 후처리 인터페이스 시험이며 실제 곤충 모델이 아닙니다.

## 3. 계산 전 조건 명세

각 케이스는 솔버 시작 전에 CONDITIONS.md와 conditions.json을 저장합니다. 입력 JSON·초기장·격자 사양·수치설정·허용오차 파일의 해시도 함께 남깁니다.

| 항목 | 현재 추적자 사례 | PH3 실험 재현에 필요한 조건 |
|---|---|---|
| 초기 농도 | mean + amplitude*cos(pi*x/Lx); 균일시험은 amplitude=0 | 단위가 명시된 공간 초기장 또는 균일값과 측정 근거 |
| 공급 위치 | 기본 확산시험은 없음; 공급시험은 자유 공기 내 지정 직육면체 | 공급 영역의 좌표·형상, 계측 또는 원문 근거 |
| 공급 시간 함수 | 기본은 0; 공급시험은 t=0부터 유한 시간 동안 정규화 생성항 | 실험의 외부 지정 공급 이력; 약제 생성 절차와 분리 |
| 벽 | U=0, 법선 확산 플럭스 0 | 재질·불투과 여부·유동 경계 |
| 시트 | 외곽 밀폐벽 근사 | 별도 전달계수·면적·단위·온도 조건 |
| 누설부 | 없음 | 위치·면적·외부 경계·측정 근거 |
| 적재물 | 가정한 다공성 직육면체 | 실제 치수·공극률·유효 확산 정의 |
| 흡착·포대막 | 흡착은 선택적 정규화 선형 교환, 포대막은 미지원 | 독립된 계수·단위·모델·근거, 중복 저항 배제 |
| 온도·유동 | 등온, U=0 | 비교 실험의 열/유동 조건과 부력 필요성 |

PH3 열의 미확정 항목은 임의값으로 보충하여 실험 재현이라고 부르지 않습니다. 현재 5톤·100포대는 실험 배경 규모이지 확정 형상 입력이 아닙니다.

## 4. 시간과 출력

- physical_end_s: 물리적 종료 시각.
- calculation_dt_s: 내부 계산 간격.
- field_output_interval_s: 농도장 저장 간격.

세 값은 분리하여 저장합니다. 현재 고정간격 계산기에서는 출력/종료 시각이 계산 간격에 맞아야 하며, 맞지 않으면 조용히 반올림하지 않고 거부합니다.

정상상태 모드는 공급 종료 후 C와 Q의 전 셀 최대 변화율과 질량수지를 검사해 지정 시간 동안 연속 통과하면 종료합니다. 최대 시간까지 실패하면 정상상태 도달로 처리하지 않습니다. 마지막 정상상태 프레임은 정규 저장 간격 사이에서도 별도 저장합니다. checks.json은 실제 종료 시각·저장 프레임 수·벽시계 계산 시간을 구분하고, progress.csv는 계산 단계별 시간을 기록합니다.

NPZ의 concentration은 [시각 수, 셀 수] 배열입니다. 모든 셀을 보존하며 shape_xyz, lengths_m, region_id, porosity 및 times를 함께 저장합니다. x가 가장 빠르게 변하는 순서이므로 [time,nz,ny,nx]로 복원할 수 있습니다. 단면 그림만 저장하는 구조가 아닙니다. 출력 시각 누락도 검사합니다. 공간 보간은 포함 셀의 일정값, 시간 보간은 선형이며 범위 밖은 무효값입니다.

## 5. 사전 통과 기준

허용오차는 protocol.py의 CRITERIA와 실행 전 criteria.json으로 고정합니다. 실패 뒤 기준을 넓혀 통과시키지 않습니다.

| 단계 | 검사 | 사전 통과 조건 | 현재 |
|---|---|---|---|
| A | 폐쇄계 질량 보존 | 상대 변화 < 1e-8 | 실제 실행 |
| A | 비음수 | 최소 C >= -1e-10, clipping 없음 | 실제 실행 |
| A | 확산 해석해 | RMSE < 0.002 C/C_ref | 실제 실행 |
| A | 격자/시간 세분화 | 각각의 오차가 순서대로 감소 | 실제 실행 |
| B 기준선 | 공기/다공성 확산 | 동일 수지·비음수·출력 완전성 | 실제 실행 |
| B 교환 | 가역 흡착·탈착 | C/Q 해석해 RMSE < 0.002, 총질량 상대 오차 < 1e-8 | SORPTION.md의 10개 실행 통과 |
| B 후속 | 비영 유동·막 전달 | 구현 전에 별도 해석해와 보존 기준 확정 | 미진행 |
| 재시작 | 연속 계산과 최종장 비교 | 최대 절대 차이 <= 1e-10 C/C_ref | 실제 실행 |
| 재시작 | 불완전 저장·입력 변경 | 이전 유효 저장본 선택, 변경 입력 거부, 원본 보존 | 실제 실행 |
| C | 실제 적재·시트·누설 | 형상·물성·경계조건 확보 및 기준 확정 | 미진행 |
| 실험 비교 | 독립 농도곡선 | 측정 불확도 기반 허용오차 사전 확정 | 자료 부족으로 차단 |

기본 9사례 묶음은 개별 검사 실패 시 다음 실행을 중단하고, A의 오차 감소를 확인한 뒤 B로 넘어갑니다. --case는 독립 개발 시험용이며 이전 단계 전체를 통과했다는 인증이 아닙니다. 한 단계의 성공으로 후속 PH3 실험 재현을 승인하지 않습니다.

## 6. 선행 실험과 실제 비교하는 절차

1. 원문 버전과 접근 범위를 기록하고 대상 적재물, 정확한 형상, 센서 XYZ, 농도 단위, 측정시각, 초기/경계/공급/열조건 및 불확도를 확보합니다.
2. 원시 시계열과 그래프 디지타이징 자료를 구분합니다. 디지타이징이면 원그림·추출 오차를 기록합니다. 해당 조건이 없으면 정량 재현 판정을 보류합니다.
3. 보정용 자료와 독립 검증용 자료를 나눕니다. 흡착·누설 등을 맞춘 곡선을 그대로 독립 검증 성공 근거로 쓰지 않습니다.
4. 센서 위치·시각에서 별도 후처리로 농도를 조회합니다. 단위변환에 필요한 온도·압력과 농도 정의를 명시합니다. 범위 밖 보간은 금지합니다.
5. 위치별 시간곡선, MAE/RMSE, 편향, 도달 지연과 실험 불확도를 함께 보고합니다. 정규화 RMSE를 쓴다면 분모도 사전에 정의합니다.
6. 허용오차는 센서 불확도·수치오차·실험 반복성을 근거로 비교 전에 등록합니다. 현재 실험 검증 허용오차는 미확정이며 수치시험의 0.002를 대체 적용하지 않습니다.

Agrafioti 2021은 확보 본문이 있으나 적재물이 쌀과 다르므로 계수를 쌀로 전용하지 않습니다. Arora 2025는 기존 조사에서 전문·센서별 원시 시계열·정확한 적재 치수가 확보되지 않았습니다. 관련 2021 학회자료를 2025 실험의 원시 데이터처럼 취급하지 않습니다. **현재 실험 재현 성공 건수는 0입니다.**

## 7. 중단·재시작과 자동 실행

```bash
# OpenFOAM 환경을 불러오고 모듈을 빌드한 WSL, 저장소 루트에서 실행
/tmp/cfd-tracer-env/bin/python -m tracer_transport.run --config tracer_transport/block3d_test.json --case porous --nx 40 --dt .005 --stop-at .5 --output "$HOME/cfd_tracer_runs/pause_new"
/tmp/cfd-tracer-env/bin/python -m tracer_transport.restart "$HOME/cfd_tracer_runs/pause_new/porous_40_0.005" "$HOME/cfd_tracer_runs/resumed_new"
/tmp/cfd-tracer-env/bin/python -m tracer_transport.test_restart "$HOME/cfd_tracer_runs/restart_check_new"
```

재개는 원본을 수정하지 않는 새 폴더에서 수행합니다. 변경된 입력 해시를 거부하고, 읽을 수 있는 완전 저장본 중 최신 시점을 사용합니다. 불완전 저장본은 지우지 않습니다. 초기 폴더의 정적 계수를 읽고 보호된 사양으로 격자를 재생성합니다. state.json/restart.json과 모든 로그를 보존합니다. 이미 끝난 계산은 재개를 거부합니다.

schema 2에서는 C와 Q가 모두 있어야 완전 저장본입니다. Q가 없는 이전 schema 1 결과의 재개는 암묵적 변환 없이 거부하며 원본 조회 자료는 유지합니다.

자동 실행은 명시된 유한 사례 목록을 순서대로 실행하는 배치입니다. 실패한 계산을 무한 재연결하거나 자동으로 0초 재시작하지 않습니다. Ctrl+C로 중단하면 해당 실행의 프로세스 그룹을 종료하고 로그를 보존합니다. 실제 PC 전원 차단, 분산/MPI, GPU, Studio 버튼 연결은 검증하지 않았습니다.
